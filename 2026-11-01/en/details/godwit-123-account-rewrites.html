A rewrite button needs to know who is sending

People who use personal and work accounts in one client need a rewrite to respect the account behind the draft. Godwit’s maintainer says Wit already obtained account context when invoking a skill, but the one-click and selected-text rewriting paths did not. They saw the requested operation and draft, without the sender profile. Version 1.23.0 supplies that missing context. A shared rewriting skill can therefore receive different defaults for different accounts. The November 1 release is the concrete event here; its October 31 Product Hunt appearance is separate discovery evidence and does not establish the client’s original release date. The practical case is switching between personal correspondence and work messages inside the same client: the draft determines which sender context the rewriting operation receives.

The immediate request takes precedence

The added context is guidance, not an instruction to paste the account profile into the message. A specific request such as formal tone should override a casual default, while the default applies where the request leaves choices open. The prompt also tells the model not to introduce a name, contact details or signature. Maintainer tests inspect the supplied context and precedence note. They do not demonstrate that a live model always follows those constraints. Plugin-based draft translation is unchanged. For a user, the useful distinction is between the client supplying the right identity and the model producing a reply that still needs review.

Stopping a link at punctuation

A second repair concerns bare web addresses embedded in Chinese AI output. The renderer previously continued until a space, so punctuation and the next phrase could become part of the destination. The release updates both the reader’s summary card and Wit responses. Follow-up commits narrow the boundary logic so it does not simply cut every character in an entire Unicode block, and explicitly written Markdown links retain their supplied targets. This removes a small but disruptive correction step after clicking a malformed address. Parsing and click tests are reported, although the maintainer explicitly says the behavior was not checked in the running app.

Drafts and attachments stay in the mail workflow

Godwit combines ordinary inbox, conversation, search and compose surfaces with summarization, translation and attachment reading. Generated replies return to an editable draft. This release also gives attachment tiles the operating system’s file-type icons, helping users recognize a document before opening it. The client keeps its mail database and search index on the computer. AI can use a local service or a selected cloud provider, so a local mail store does not mean every AI operation is offline. Remote images are blocked by default. Sending requires approval, while the separate MCP interface for other agents permits reading and draft creation rather than sending.
