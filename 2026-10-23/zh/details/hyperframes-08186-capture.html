这次新增的是画面结果，而非再次推出编辑器

HyperFrames 把 HTML、CSS、媒体和可定位时间的动画渲染成视频，个人创作者既可通过编码 agent 使用，也可在 Studio 中看画面与时间线。10月22日17:28 UTC发布的0.8.186把可选的捕获式运动模糊接到渲染和 Studio，并新增整段录音的语音、音效、音乐阅读结果。它与10月6日已报道的0.8.137预览内存优化不同，不能把桌面编辑器当成今日首次出现。开源仓库及 Apache2.0许可证已核对，版本发行资产主要是 agent 插件和渲染服务文件；当前桌面安装文档另列 Mac 与 Linux。这里确认代码和发布资料可得，没有安装应用、导出样片或证明每一桌面安装均已收到同版更新。

预览不能呈现的模糊，不偷偷出现在导出里

创作者要显式在合成根节点的 HTML 中开启 data-motion-blur，脚本事后改属性不算。页面通过浏览器捕获把快速移动元素沿路径混合，Studio会把自身浏览器是否支持所需能力随渲染请求传递；预览不支持时导出也关闭这一路模糊，避免成片与编辑时看到的效果分离。另一种引擎子帧模糊与页面模糊不会同时运行。开发者示例比较同一帧的文字、盒子和图钉拖影，但这是实现者演示，不能推出任何素材都同样好。大面积半透明元素、部分三维变换和SVG等存在处理限制；透明物体可能带出背景光晕，拖影也可能穿过遮挡或裁切边界。

[S86]

关掉效果时给出原因，导入时尊重手机画幅

检查命令现在区分效果被关闭、没有足够快的移动物体、以及浏览器无法验证三种状态；关闭提示带原因与修复方向，例如调整根节点的混合模式、把不兼容效果另行渲染，或放弃模糊。这样用户能判断是自己没有开启、素材不需要，还是渲染路径不支持。开发者报告启用后渲染中位耗时约为原来的1.7倍，属于其测试而非我们的测量。另一项实际变化是 init --video 根据播放时的比例建立画布，短边1080；竖屏为1080×1920，4:3为1440×1080，并考虑旋转标签和非正方像素。显式选择分辨率仍优先，选择其他示例模板也保留模板设计。

让 agent 读懂整段声音，但不把估计当逐轨真值

新增 audio --read 将整段节目或参考视频变成带时间的三类行：语音包含文本、语速、音高偏差及停顿；音效按起音与规则归类，重复声音可分组；音乐识别片段、中断和再次出现。用户或 agent 因而可按时间寻找节奏位置，而不必只看单个声音测量。它需要转写与分离音轨：缺少分轨时只能在语音外估计混合音效，不读音乐；两者都没有时不假装能分开人声和配乐。默认 local 不上传，best 会上传给已配置服务并使用相应账号，后端接口实现另属一项变更。发布者仅给出合成信号和本地模拟服务测试，以及一次作者自报实验；尚不能保证线上服务可用性或每个音效名称准确。

[S87]

人仍能接管时间线，成本也不止开源代码

Studio 的既有操作链是描述视频、在画面上选择或画记、给时间点加评论，再把待处理修改合并交给 agent；也可直接移动、裁切片段或改速度、音量和淡入淡出。运行中的消息默认排队，用户可改成停止当前运行后按新指令重来，每次 agent 运行有撤销入口。这些是已有工作方式，不计作0.8.186新增。当前桌面指南要求 HeyGen登录，CLI README要求Node22以上；自己的编码agent、媒体生成或云端声音服务可能另有账户与费用，开源许可并不等于完整流程免费。相较手工剪辑，价值假设是保留可修改工程的同时减少agent描述声音和画幅的误差；不愿维护本地环境的创作者仍可能更适合现成编辑器。
