Start with the demonstration brief

Making a product video often involves moving among recording, scripting, title design, narration and export tools. Video Studio Skill organizes those steps for Claude Code. The brief supplies a URL, audience, message, scene beats, brand material and duration before recording begins. Playwright captures the actual browser interface; HyperFrames composes titles, chapters and closing material; FFmpeg and ffprobe handle exports and media checks. A thumbnail and contact sheet help the creator inspect what was produced. Narration, subtitles and supplied footage are optional layers rather than mandatory paid generation steps. The resulting workflow is intended to reduce tool handoffs while retaining inspectable intermediate files.

The fixes target the first composition

Version 1.0.1 was published at 18:11:11Z on November 2 and addresses concrete first-run failures. After recording, a new project already had a directory, causing the old initialization step to fail; composition now uses a template. The silent example referenced narration that did not exist, so it now creates a silent track first. The capture helper also changes local dependency installation and exposes errors. The author reports fresh-clone capture, silent rendering, local narration and thumbnail checks, but did not rerun the complete live Claude quickstart. Avatar, multiple-environment and macOS paths remain outside that reported validation. Partial successful runs do not establish universal one-command setup.

Distinguish capture from planning and reenactment

The project distinguishes what its demonstrations actually show. Its short example records a real Claude session producing a brief and three scene beats. It does not perform browser capture or final rendering, and waiting intervals are removed. Terminal scenes in the longer introduction include authored HTML reenactments, so that film cannot prove every shown command ran live. For a publication-ready walkthrough, inspect whether important clicks came from the intended product version, whether captions obscure the outcome, and whether narration claims capabilities absent from the recording. Automated composition can reduce assembly work, but responsibility for the visual evidence and product claims remains with the creator.

A reusable workflow still needs a working environment

This is not an installation-free video website. The full workflow needs local tools including Node, a browser and FFmpeg, plus an authenticated Claude Code setup. Model usage and optional services have their own costs. The repository uses MIT licensing, while external tools, models and media retain separate terms. Compared with recording and editing manually, it is most relevant to someone repeatedly updating demonstrations of the same product, retaining briefs and assets between revisions. Start with a short public workflow and inspect the actual interactions, exported file and sound before adding more generation. If small revisions repeatedly require script repair, the automation may not reduce total production time.
