  1. 01Atlassian AMP2026-10-06 · developer surfaceThe product value is moving agent work from a private window into a space the team can inspect together. Colleagues can see who triggered an agent, what it touched, what it changed, and who owns it; a coding agent running locally is no longer a black box outside Jira. For design, product, and engineering teams, artifacts, comments, selections, and acceptance criteria become agent context instead of material that someone must copy and explain again.
  2. 02OpenAI Decisions API2026-10-06 · developer surfaceThe API extracts a common product step—classify, then decide what happens next—from a long-form generation chain. Image moderation can return whether a rule is met, a router can choose one action from a fixed tool set, and a workflow can score an input before escalating, rejecting, or handing it to a person. For HCI, the important change is that model judgement becomes an observable system state rather than a decision hidden inside prose.
  3. 03femtoAI opens an SPU developer surface for smaller edge-AI systems2026-10-07 · startup signalThe product signal is about turning the edge-AI problem—too large, hot, and power-hungry—into a toolchain developers can try. The evaluation kit lets a product team test target models, voice, and sensor tasks against memory and power before deciding whether an SPU belongs in earbuds, glasses, home appliances, or a robot. It does not guarantee better recognition and does not make an evaluation board a mass-produced device.
