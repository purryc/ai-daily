Start with a baseline, then notice changes

Checking a school website for another announcement is an easy task to forget. IFTTT’s AI Agent makes a public page a trigger source: point it at a list of updates, and the entries present at the initial check become the baseline. Later additions can start an Applet. A second trigger watches a named number, using the page’s own wording to identify it, and reacts to a threshold crossing or any change. The result can become a phone notification or feed another connected action. The documentation explicitly excludes some stores and pages whose content loads through JavaScript. A page being readable to a person does not by itself establish reliable automated extraction.

Turn a bill into a dated item

Natural language also determines work performed after a trigger. In the official bill example, the agent reads a Gmail message, finds a due date, checks Google Calendar for a matching company and date, and creates an all-day event only when no matching event exists. A message without a due date is skipped with an explanation. The input therefore includes the triggering email and authorized connections as well as an instruction; the output changes another application. Explicit duplicate criteria and a named destination calendar leave fewer decisions implicit. IFTTT Chat can draft the whole Applet for inspection, while the Classic builder remains available for selecting components manually. Newly created rules are private by default.

Generate action text for each event

AI Action assist is a switch on an Applet action, rather than a separate scheduler. The user adds instructions for a subject, message or body; each trigger supplies fresh material for the generated text, and irrelevant input can be skipped. A news workflow, for example, can summarize a selected topic while recording a reason for ignoring other stories. Only one action per Applet can currently use this option. It reduces the need to maintain many rigid message templates, but correct filtering still depends on the actual input. The activity page distinguishes completed work from skipped work and records explanations, helping users distinguish silence caused by no new event from silence caused by an AI decision.

Unlimited rules still have a running cost

The commercial change opens core multi-action rules, queries, filters and service access across plans, with credits limiting execution. Free supplies 1,000 credits monthly; Applet runs, MCP use and AI features draw on the allowance, so 1,000 credits should not be described as 1,000 complete jobs. Paid tiers add capacity, faster checks and some account capabilities. The documented polling intervals are hourly on Free, every fifteen minutes on Starter and every five minutes on Pro or Pro+, making website alerts periodic checks rather than a live feed. Prices shown as monthly equivalents can be billed annually. Actions also need careful configuration: the founder’s public reply says a general confirmation step before an Applet executes is still absent.
