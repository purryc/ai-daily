Give the agent the place the reviewer is looking at

After noticing a weak derivation in a PDF, an author normally has to locate its source before requesting an edit. Papilot accepts a text selection or marked region directly on the rendered page. SyncTeX provides the connection to the source file, giving the task a location rather than only copied text. This fits revision of an available LaTeX project; it is not reconstruction of arbitrary scanned documents. The interaction also changes who can contribute feedback: a reviewer can begin with the page a reader will see, without first learning how the source files are organized.

Keep related comments together

Version 0.7, released October 31, adds color groups whose annotations can share an instruction and be sent individually or together. A notation change can carry both its locations and a common explanation, reducing repeated setup. Local exceptions still matter: similar symbols may mean different things in different chapters. Grouping is useful organization, not a decision that every marked passage should receive the same replacement. After recompilation, annotations whose positions cannot be confirmed are flagged. That is preferable to quietly attaching a reviewer’s instruction to a different passage and letting a later task treat it as intentional.

[S12]

Separate approval from handing over the revision

Typeset before-and-after views place a change back in the manuscript’s context, with acceptance, rejection and comments available per edit. For new tasks, version 0.7 keeps accepted changes inside the task until the reviewer chooses delivery to the working directory or a separate branch. Existing tasks retain their earlier behavior. In collaborative writing, this distinguishes approving an individual revision from handing over a whole revision round. A practical trial should check both the untouched passages and whether the delivered file contains exactly the accepted set. The interface’s completion label alone cannot establish either property.

[S12] [S10]

Compilation and reasoning fail differently

The workspace requires Node.js, Git, a TeX installation and an available agent. Import can identify a main file and compiler, but a broken project still needs repair. The software is MIT-licensed; model service charges follow the user’s provider. It therefore fits authors who already maintain LaTeX projects. Compared with asking a coding assistant to revise a directory, PDF differences make layout, numbering and equation presentation easier to inspect, without verifying the argument. A familiar short paper can test prose, mathematics and cross-file references. If repairing compilation costs more effort than the earlier manual workflow, broader delegation is premature.
