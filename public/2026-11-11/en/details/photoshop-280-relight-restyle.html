A generated result still needs revision

Photoshop 28.0 addresses what happens after an image has already been opened and a first edit has been generated. A client may ask for warmer light or a less pronounced treatment while expecting everything else to remain stable. Repeating a prompt is an awkward control for that request. The November release lists Relight, Generative Restyle and Quick Compare as complementary ways to adjust lighting, refine a generated treatment and inspect the difference. These are editing interfaces for existing images, not new camera or sensor hardware. The announcement and documentation carry November 10 dates without an exact rollout timezone.

[S30]

Preview the lights before the final render

Relight starts from a supported unlocked layer. The editor adds up to three lights, moves them on the canvas and adjusts color, intensity and diffusion. A low-resolution preview updates during adjustment; Done creates the full-resolution result on a separate layer. The original remains underneath, but the operation affects only the selected layer, a significant distinction in a composite. Internet access is required, and each completed render costs 30 generative credits, including a later completed revision. A practical consequence is to settle the target layer and approximate light placement before paying for the final render.

[S31]

Turn a prompt result into an intensity control

Generative Restyle begins with an edit already produced through Prompt to edit. Converting that result creates an editable layer and a custom slider in Properties and the contextual controls. The person can reduce or strengthen the treatment instead of writing a new instruction for every intermediate version. Creating the Restyle layer costs 80 credits; the result can be captured as a layer or exported as video. This offers a useful degree-of-change control, not a guarantee that every texture or branded detail remains unchanged. Product markings and fine edges still deserve comparison with the source.

[S32]

A convenient comparison can expose excessive editing

Quick Compare opens from the toolbar or View menu and can receive a keyboard shortcut. It compares the original document state with the current edit in horizontal, vertical or single-view arrangements. That removes repeated layer toggling from a routine before-and-after check. For generative relighting, the comparison should include skin texture, reflections and fine lines, not merely overall mood. Keeping the original layer makes recovery easier but does not establish fidelity. A harmless sample and a close inspection of one important detail are sensible first checks. No Photoshop session, generation-time measurement or fidelity benchmark was performed for this article.

[S33]

Keep the release separate from previews

The same event also showed experimental workflows, so the release should not be read as one promise of immediate availability. Adobe still labels Camera Angles, Mockups and conversion of flattened image text to type layers as beta. Local MCP connections are previews planned for early 2027. An editor should check the installed version, individual feature label and displayed credit requirement before planning a job around them. The practical benefit here is fewer repeated prompts and comparison steps within an existing image workflow. The person making the image still decides whether the changes are appropriate and sufficiently faithful.
