Retrieve earlier writing without leaving the paragraph

TK places an @TK request inside the document being written. A writer can ask a small factual question or retrieve a passage from an earlier note without opening a separate chat. Inputs can include rough notes, voice captures, prior Medium writing and imports from existing note collections. The output remains material to inspect and revise. This addresses a concrete interruption: leaving the draft to locate something already written. For a growing archive, retrieval should be checked against the original passage, especially when the author’s view changed over time. A fluent synthesis can otherwise erase disagreement or make an abandoned position sound current.

Machine critique and human reading remain separate routes

Editorial and headline skills offer one route to feedback; libraries shared with other people offer another. These are different sources of judgment. A quick structural suggestion does not establish how a reader will interpret an argument, and sharing a draft is different from publishing a finished story. The announcement also describes displaying human and AI contribution information. That is a disclosure surface, not proof of detecting every externally generated passage. A practical comparison would retain an original paragraph, collect machine suggestions and human responses separately, then inspect which edits improve the intended meaning. No manuscript comparison or reader study was performed for this item.

A connected daily note is updated in place

Medium’s public Daily Note plugin gives the notebook a concrete external-agent workflow. It creates a daily record, carries unfinished items forward and can draw linked tasks from separately connected work services. The README specifies targeted edits rather than replacing the page, preserving manual text and checkbox state. Missing connectors leave their sections empty. Persistent preferences live in a separate private memory document. These are implementation intentions, not tested guarantees. Scheduling is a separate user setup step; installing the plugin does not establish an active recurring run. The useful adoption check is whether an imported task retains its source and whether a refresh respects a person’s concurrent edit.

Cloud collaboration still carries permission and migration costs

The product supports Markdown import and archive export while choosing cloud collaboration rather than a local Markdown-file foundation. A native desktop application remains on the roadmap. The maker lists unlimited notes, publishing and collaboration in the free tier, with a $12 monthly Pro tier for full agent, skills, summaries and MCP access; the post does not explicitly establish currency. Free note storage is therefore not an unlimited AI-use claim. The no-training statement also does not mean local-only processing. November 9 is the opening reported here, with the next day’s Product Hunt appearance treated as discovery rather than another first release. Early-user enthusiasm cannot establish general writing improvement.
