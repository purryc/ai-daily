A screenshot is the beginning of an action

A user might supply a product photograph to find a matching catalog entry, or a technical drawing whose information needs organizing in another application. Terra accepts text and images, then produces text or tool calls. The host turns those calls into clicks, typing or other operations and returns the resulting state. This division helps locate a failure: incorrect visual interpretation, wrong arguments or an execution problem. The model documentation does not support native audio or video input. An advertised video-editing task therefore does not mean that sending a movie directly to the model completes the job; software and tools still participate. Useful feedback identifies the action and its actual result.

Count retries alongside token prices

Standard API input and output cost$1 and $5 per million tokens, with cached reads at$0.05. The model page separately lists cache-write charges and higher rates for requests exceeding272K input tokens. The cheapest cached rate therefore cannot be applied to every document. In an invoice-entry workflow, repeated screenshots, reruns after omissions, long context and human review all affect cost. Someone purchasing a completed service needs an estimate of the actual call sequence rather than one line in a model pricing table. Lower unit prices may suit frequent small tasks, but manually re-entering a failed job can consume more value than the saved inference charge.

The model can change while the acceptance task stays fixed

OpenAI reports improved computer-use and visual reasoning results, alongside factuality and coding evaluations. These are vendor measurements rather than success rates for an individual business process. A form-entry comparison can retain blurred screenshots, similar fields, missing information and failed saves, checking whether the model asks for clarification or fills gaps itself. Replacing the model does not change the application’s business rules, so the same acceptance task makes differences in speed, omissions and retries easier to interpret. Reasoning effort is configurable, but increasing it does not automatically repair permissions, input quality or an incorrect saved record. Producing a plausible answer must remain distinct from saving the intended result.

Availability still depends on the account and host

The API changelog records October 26 as the release date, and the system-card addendum carries the same date. The announcement body gives no exact clock, so this issue treats the event as a recent supplement. Listed ChatGPT Work and Codex plans include Plus, Pro, Enterprise and Edu; developers also have API access. This does not establish equal allowance on a free plan, and subscription entitlement should not be combined with API billing. The system card describes model training and evaluations, not a universal approval, undo or recovery implementation in every connected application. Without authenticated testing, model availability, connected tools and reliable task completion remain separate findings.
