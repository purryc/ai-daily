Use the model files already on the drive

Trying several local AI tools can leave model files scattered across drives. Llama Windows puts a chat entry in the system tray and manages a llama.cpp server underneath it. Its ordinary downloads use the Hugging Face cache. Version 0.13 adds another route: register a folder of GGUF files already on the computer, and the app discovers them recursively, shows their metadata and makes them loadable without another copy. Users retain their chosen storage locations. That is useful when storage organization predates this particular application. The October 25 Product Hunt listing is a discovery route; the substantive update discussed here was released on October 20.

Memory fit before download, performance after loading

Model details already offer context-length choices with memory estimates. The new fit verdict compares estimates derived from GGUF headers with available system and device memory, then explains the result on hover. It gives a prospective download a clearer resource check than the model size alone. Separately, compatible models with mtp, dflash or dspark draft heads can have speculative decoding configured automatically, including a reload action for a model already running without its head. The maintainer describes a potential speed improvement, not a measured guarantee for every computer. A memory verdict and a responsive application are different questions: the former cannot establish answer quality, sustained throughput or the waiting time in a particular workload.

Bring material in from another application

Alt+Space opens the loaded model’s web chat in an overlay. Hiding it preserves the conversation for the next invocation. Windows sharing now provides an additional input route: text or an image selected elsewhere can enter the chat composer before the user continues the request. An image reaches the multimodal path, but that does not make every downloaded language model capable of interpreting it. Deep links can open a chat or request a model, with the identifier checked against what the server actually has. Compatible editors and scripts can instead connect through the local OpenAI-style API. They still need the correct server address and a model suited to the task.

Local inference still involves downloads and maintenance

The README says prompts and inference remain local and the app sends no telemetry. Model downloads and release checks still make network requests, including a user-agent string identifying application version, Windows build and architecture. Local inference therefore does not mean no network traffic. Version 0.13 also corrects a misleading running state: a failed model-list request is checked against the server health endpoint before reporting that the server stopped responding. For a tray app left open all day, that makes the visible status more useful. The project uses the MIT license and supplies Windows 11 release packages. Automatic Store submission still depends on certification, and concurrent requests for different models have not been independently assessed here.
