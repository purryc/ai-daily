Hide editing gestures without blocking ordinary viewing

dumbTV home presents installed apps and HDMI inputs as tiles controlled with a remote. Normally, holding OK or pressing Menu exposes Move, Rename, Hide and App info. Launcher version 1.5 adds an optional child lock that hides Options and Settings and disables those editing gestures while keeping ordinary app and input selection working. Hold Menu for three seconds on Home to reopen Options and turn the lock off. The interaction addresses accidental rearrangement or hiding of familiar apps without asking for a password whenever somebody wants to watch television. The configuration file can also clear the state, but the normal escape remains a remote gesture.

An accidental-edit guard, with clear boundaries

The release explicitly separates this lock from parental access controls. Holding Home still opens Fire OS’s own quick menu, and remote app shortcuts or a dedicated Settings key can continue to work. The launcher does not own those system entry points. Families needing a PIN are directed to Amazon’s existing parental controls. Within the home screen, rows or a wrapping grid, tile sizes and label visibility let an adult arrange the common destinations before enabling the guard. The launcher has no INTERNET permission, so Android prevents it from opening a network connection. That statement applies to the launcher, not the computer-side installation and restoration tools.

Wake handling fills a missing window event

Version 1.4 addresses a different interruption: Fire OS can restore Amazon’s home after standby without emitting a new window-state event, so dumbTV’s guard never notices the change. The update remembers the foreground package and checks it when the screen turns on. Netflix and other applications remain open, and deliberately visiting Amazon’s home keeps the guard paused. A contributor observed about thirteen seconds of the old behavior on a second-generation Fire TV Cube running Fire OS 7.7.1.3, then immediate return with the new logic through remote and Alexa-routine wake-ups. Crucially, this used a personally customized build with the same logic, not the exact submitted branch’s APK.

Memory feedback observes, while setup handles interruptions better

The optional memory meter is off by default. It shows available memory and an occupancy bar, turning amber when Android reports low memory or less than fifteen percent remains free. It only displays those readings; it neither closes applications nor proves a speed improvement. Related installation changes stop treating a disconnected television as evidence that a package is absent, handle sleep interruptions and write the Home-related setting to its newer Android location. Undo preserves prior settings. The broader project supports coding-agent assistance for customization and setup, but these releases change ordinary Android interfaces and scripts. Practical results still depend on firmware and the system functions an owner wants to retain.
