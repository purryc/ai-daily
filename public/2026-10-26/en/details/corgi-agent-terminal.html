Start from a project folder

Run Corgi in a project folder, choose a shortcut preset, and use the launcher to start or resume an agent. Workspaces retain folders, tabs and split panes; the sidebar distinguishes active work from requests for attention and completed turns. F1 moves to the next attention item. The README lists Claude Code, Codex, Pi and OpenCode, but their integrations differ: Codex hooks require trust once per account, Pi uses an extension, and OpenCode needs no corresponding setup. A failed usage reading does not necessarily prevent launching. Account login, hook trust and agent status therefore need separate checks when the dashboard looks incomplete.

Return review notes to the working agent

The review panel follows the focused pane’s checkout. Its default comparison includes changes since the branch diverged from the default branch; users can instead inspect uncommitted work or one commit. Move through files and hunks, select lines, write notes, and paste them back into the agent pane. The panel reads Git without changing the repository. It does not press Enter after pasting, and copies notes instead when a bare shell lacks bracketed paste. Pinning keeps the same checkout visible while switching agents. Binary or oversized files produce a notice. Notes belong to the current viewer and disappear when it exits, so this is an immediate feedback surface rather than a durable review archive.

Detachment, closure and recovery differ

Detaching leaves the runtime and its processes alive; running Corgi again reconnects. Closing a tab or pane instead terminates its processes. After a crash or reboot, saved layout and output return, recorded agent conversations wait dormant until focused, and ordinary panes start fresh shells. Import also has explicit boundaries. A tmux import copies layout and recent output while source processes stay in tmux; suggested restart commands do not execute automatically. A compatible Herdr handoff can transfer the running session itself. Copying cannot preserve arbitrary application memory or a shell environment. These distinctions matter when moving a busy workspace: reconnecting a conversation is a narrower guarantee than restoring every process exactly where it stopped.

Platforms, scripting and remaining limits

Corgi uses the MIT license. Its installer documentation names Apple Silicon macOS and amd64 Linux; the author describes Windows support through WSL2. Existing agent accounts supply inference, including optional model-assisted organization, so an open-source terminal does not make provider usage free. The CLI can list panes, read output, split a pane and send literal text; submission requires its explicit Enter option. The official SSH image-paste demonstration requires Ghostty Nightly. Native cross-machine remoting remains unfinished according to the author, although ordinary SSH can reach a runtime on its host. Public comments also report repaint flicker without a confirmed reproduction. Those reports describe early user experience, not a measured reliability rate.
