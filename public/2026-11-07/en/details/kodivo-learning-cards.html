Keep code and explanations inside short lessons

A short lesson can preserve the important parts of an explanation rather than merely compressing a topic into a slogan. Kodivo’s maker describes examples, exercises and reasons for the answers, with the PHP path connecting code and output to documentation. That format suits a learner who has a few minutes available and does not want to relocate a passage in a long video. It also creates a specific limitation: recognizing an answer after seeing it is easier than producing working code unaided. Explanations matter when they identify the mistaken step in someone’s reasoning. A completion counter alone would say little about whether that misunderstanding has been corrected.

Learn the work around a coding agent

The maker’s lesson image gives a concrete contrast: a vague request to improve an app versus a bounded change to rename a task-note form’s Save label to Save note, preserve saving behavior and reopen a saved note to check the result. This puts the requested change, the behavior to retain and the acceptance step on one card. A learner can see why the task is checkable instead of merely memorizing prompt wording. Context selection and reviewing agent output belong to the same path. Real projects introduce more dependencies; the public material does not establish comprehensive coverage of production permissions, deployment or incident response.

Continue through MCP without restarting the explanation

Connecting an existing agent through MCP makes saved learning state available outside the browser lesson. The practical benefit is continuity: a person need not begin each session by narrating what they have already studied. Progress still needs careful interpretation. Viewing a card, answering one question correctly and mastering a concept are different states. An agent receiving that history should not treat a coarse progress label as a complete assessment of ability. It may offer another explanation or example, but that new material can introduce errors of its own. The launch description does not provide a complete connector permission or retention account, so successful private synchronization cannot be assumed from the integration label.

[S06]

Inspect the lesson before saving progress

The public demo needs no account, and the maker describes both current learning paths as free. Registration becomes relevant when someone wants to retain progress for the next session. A learner can therefore read code, inspect its output and examine an answer explanation before adopting another account and study routine. Documentation serves a quick definition lookup; a longer course develops a topic continuously; a general assistant handles an immediate follow-up question. Kodivo packages smaller lesson units while retaining links to documentation and an external assistant. Cards organize the next step, documentation supports checking, and the assistant can continue an explanation. Its November 6 PH appearance establishes neither first availability nor course-completion outcomes. Platform points include shipped-feature credit and are not learner counts.
