The browser belongs to the current conversation

Unsloth lets local models read pages, fill forms and work alongside files. Beta 0.1.916 gives separate chats their own browser use and allows the built-in browser to become a movable, resizable floating window. Previously, choosing the floating layout could affect later chats. The choice now belongs to the conversation, surviving a close or a switch while other conversations retain their own layout. This can reduce panel switching when someone compares a page with the model's explanation. It can also leave more browser work active, so the practical benefit depends on whether the machine keeps typing and generation responsive under the added load.

A floating window can cover the composer

The implementation permits the window to move over the composer or header and grow to the chat's full height, with stacking that keeps it in front of chat controls. Docked width remains adjustable, and the header retains its browser button while the window floats. The author checked these interactions in web Studio but did not run Desktop's native WebViews in that test environment. That distinction matters when interpreting the evidence. More placement freedom helps with side-by-side inspection, yet it can cover input, stop controls or status. A useful interface makes returning to a clear layout easy rather than assuming that unrestricted placement is automatically easier to understand.

Two-card work depends on how the model splits

The release also changes some local generation paths. With two matching idle NVIDIA cards and a model that fits on one card, selected models can share parts of each generation step; FLUX and Lumina 2 instead divide an even batch of images. Published speed figures come from the author's stated setups, not every model, memory size or driver combination. This part affects waiting time and memory pressure more directly than the window layout. A useful comparison fixes model, resolution, batch and seed, then records complete-job time and failures. Selecting only a fast internal step would not establish the benefit for someone waiting for the finished image or video.

Local inference does not make every action offline

Official downloads cover Windows, macOS and Linux, alongside web Studio and the code-based library. This is software for running and training models, not a new hardware device. A free open-source client still consumes local resources, and cloud model connections retain provider conditions. Browser access, external integrations and remote exposure do not become offline merely because inference is local. A practical trial opens different pages in two tasks, switches between them, closes and restores the browser, and checks page and layout ownership. Long-chat input responsiveness should be measured at the same time. The goal is to preserve task context without creating confusing visual state across conversations.
