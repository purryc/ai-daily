The message is still there when the user returns

crystl calls projects gems and sessions shards, organizing several coding agents working through terminals. Floating cards name the project and session so a person can approve, answer or dismiss without hunting through terminal windows. The November 6 version 2.276 addresses a specific failure: an ordinary agent card previously folded after forty seconds, so the agent could say it had sent something while the returning person saw nothing. Ordinary cards now remain until dismissed. Cards containing a question or button already behaved that way. The change is persistence for missed informational messages, not the first introduction of the entire notification system.

Rollback starts when a previous build is retained

Version 2.275 adds update rollback on the same date. Installing an update retains the replaced build; choosing it from the menu or settings quits the application and opens that version while preserving projects, sessions and settings. The vendor explicitly notes that retention happens at update time, so the first rollback becomes available only after a subsequent update. It does not undo code changes made by an agent or restore external service state. Teams depending on long-running sessions should check application rollback, repository history and file backups separately. One convenient control should not be interpreted as a transaction that reverses everything the agents have done.

Separate branches do not constrain every write

Parallel sessions use Git worktrees, giving each agent a separate directory and branch while leaving merge conflicts possible. The documentation says structured writes from Claude Code and Codex have path checks, but arbitrary Bash writes are not generally confined, and other terminal agents do not receive identical enforcement. November 6 changes also recognize custom Claude wrapper commands so startup, resume and prompting follow the appropriate behavior. That does not raise the isolation level automatically. Users need to inspect the actual agent and command in a session rather than infer equal constraints from a common interface. A shared visual wrapper cannot substitute for the underlying execution boundary.

Keep the queue of cards manageable

crystl currently targets macOS. Free Apprentice includes isolated worktrees, floating cards and the activity view; Guild adds agent orchestration, unlimited scheduling and multistage sequence execution. The page displays $170 per year but does not establish its currency here, so no conversion is warranted. Model or agent subscriptions remain separate. Persistent cards may reduce missed messages or create another inbox. A trial should record both missed questions and duplicate reminders, and confirm that dismissing a card only dismisses the notice. Switching an entire project to automatic approval changes execution authority and should not be treated as ordinary notification cleanup.
