ClipsPal 1.20.0 · Consumer creation software / product update

ClipsPal keeps automatic cuts editable and adds control over where the video library lives

The first cut remains open to correction

ClipsPal starts with recorded material: import a video, audio file or folder, choose language and format, then set how much automatic visual and sound treatment to request. Local preparation and transcription precede the AI edit. The result remains a timeline rather than a single flattened output. The guide describes a Removed view for restoring discarded passages and a Need decision queue for comparing original and proposed cuts. That gives a creator a place to examine whether a pause was an error or part of the delivery. A shorter result alone would not establish a better explanation. We have read these controls, not exercised them on a recording.

This release addresses the location of media

The dated 1.20.0 release addresses storage: relocating a library, choosing a folder for a new video, and finding a library or video after it has moved. It also lists a Chinese speech-recognition fix without a quantified accuracy result. These are concrete changes for recordings that outgrow a system drive. They do not constitute evidence of a backup system or recovery from every disconnected-drive scenario. For an external-drive workflow, the useful adoption check is whether an existing project still resolves its original clips and whether an export references the expected files after a move. This issue treats the November 8 release as a recent supplement, rather than recasting the November 9 Product Hunt appearance as the app’s first availability.

Separate local footage from material sent to the model

The vendor says source video, audio and transcription remain on the computer. Cloud-assisted editing sends the transcript and request, and its detailed FAQ adds that tasks inspecting reference images or visual media may send those too. That qualification matters more than the shorter “only the transcript” headline. A local model is another option, while license activation and voluntarily submitted feedback are separate data paths. Manual trimming and transcript correction remain available alongside Director instructions. Output can be an MP4, subtitles or an editable timeline for Premiere Pro or DaVinci Resolve; keeping referenced media available remains the creator’s responsibility when moving that project.

Desktop support and an upcoming connector

The download page lists 1.20.0 for macOS 14 or later on Apple Silicon and Intel, plus an unsigned Windows 11 x64 beta. Windows supports the editing workflow but lacks the Mac-native screen/camera capture and background-removal features. Transcription implementations also differ. The site displayed a one-time $59 price and two-computer license; the read page did not explicitly establish currency, and an underlying AI plan is separate. There is also a material availability conflict: marketing advertises 23 MCP tools, while the dedicated guide says the current public download does not include MCP yet. We therefore describe that connection as upcoming, not as a feature readers can already rely on.
