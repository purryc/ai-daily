Start with the people and materials belonging to one project

The November 9 desktop release adds team collaboration, event-triggered work and continuation across devices. A team starts in the correct organization, creates a project space, invites colleagues and connects relevant discussions or files. Linking a group does not automatically enroll everyone in it. This distinction matters when project information crosses team boundaries: a useful shared context still needs the right membership. The desktop-browser collaboration guide also excludes mobile web and embedded DingTalk pages from that entrance. The practical gain is less repeated preparation of the same background; it does not establish that every linked source was read correctly or that all members can see every resulting document.

Filter the event before turning it into work

Automatic tasks separate scheduled work from business events. A user chooses message, approval or task changes, applies conditions and specifies the resulting operation. One task can watch up to ten events, with availability varying by account; approval reassignment is not supported. Execution can use the cloud or the current computer. For recurring quotation requests, a bounded first use would create a source-linked task or draft for review. That is an editorial adoption suggestion, not a tested workflow. Retaining the original event alongside the result would help distinguish a missing message from a condition that correctly excluded it, or from an agent that failed after starting.

[S30]

Point to the exact part that needs revision

Co-editing lets a person select text, cells or a page region before submitting a revision. Selection alone does not execute the change, and the cited location should be checked before sending. People can also edit manually and then ask the model to continue. Online files retain their permissions; local Office editing depends on an enabled desktop version. This reduces the effort of explaining where a revision belongs. It does not transfer responsibility for dates, formulas or decisions to the model. A useful review compares the requested local change with the preserved parts of the artifact, rather than judging only whether the latest output reads more smoothly.

[S31]

A phone controls the task without changing where it runs

Remote continuation requires the same account and organization, an enabled target computer and a running, connected client. It neither converts local work into cloud work nor synchronizes every computer file to the phone. Closing the control page is different from stopping a task. The China web entrance uses DingTalk or a mainland mobile number. Observed recurring personal plans list 78 and 158 yuan monthly; those prices do not establish enterprise permissions. Image and audiovisual workloads also need a separate credit check. Before relying on an unattended task, a team should be able to identify its execution location, access scope, current status and actual consumption as parts of the same job.
