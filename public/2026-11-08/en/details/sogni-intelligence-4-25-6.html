Generation size and selection coordinates are different constraints

When an AI editing workflow receives a video and selects an object, the resulting mask needs to fit back onto the original frame. Version 4.25.5 of Sogni Intelligence Client repairs a wrapper path that could apply generation-model sizing rules to a selection operation. Ordinary generation can be constrained by a model’s output grid and size envelope. SAM3 video segmentation instead establishes a selection on existing footage, so rewriting its width, height or reference media can undermine alignment. The new path preserves source geometry even when generic automatic sizing is enabled. This repairs input handling; it does not claim that the model has become more accurate at recognizing objects.

Preserve metadata through the wrapper

The implementation examples pass video bytes, a text prompt and a selected frame index, checking that dimensions and fractional frame rates reach the underlying SDK. SAM3 validation permits integer dimensions from one through 2,560, while ordinary generation keeps its own limits. The release does not relax sizing for every video model. If the caller omits width, height, frame count or frame rate, those fields stay absent for server-side probing rather than being filled with invented defaults. This is a useful integration distinction: a visible failure may originate in a convenience wrapper that altered the asset before the model ever received it, not in the model’s segmentation logic.

Reference order is part of the input

The following 4.25.6 release pins an underlying JavaScript client that carries GIF reference support into direct image projects while retaining reference order. Existing wrapper defaults and hosted-tool argument shapes stay unchanged, so callers are not being asked to redesign every interaction. The release does not establish that all GIF frames now drive video according to a new temporal editing rule. The supported claim is reference support carried through a dependency, not a new timeline editor. Grouping it with the selection fix makes the common increment clearer: preserving the material an application hands into a creative-agent workflow, rather than announcing another end-user generation product.

Creative-agent integration still has operational work

The package connects applications to Sogni-hosted image, video, audio and chat capabilities, with argument validation, asset references, run records and credential redaction helpers. A long-running service needs a stable app ID to recover work, and two simultaneous processes must not share that identity. A failure after the service accepted a project should not be mistaken for an unsubmitted request and regenerated blindly. These existing operational constraints remain relevant alongside the media fix. Readable public code does not mean hosted generation has no account, balance or network cost. Release and code-test records were inspected, but no footage was uploaded or executed, so mask quality across real videos remains unverified.
