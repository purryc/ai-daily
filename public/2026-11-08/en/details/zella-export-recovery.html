Zella Mac 1.0.11 · Product / official update

Zella fixes exports stalled by sped-up clips and makes lack of progress visible

An export has to finish, not merely start

A video that plays inside an editor is not yet a file that someone can upload or send. Zella’s November 7 Mac 1.0.11 release addresses a specific failure: projects containing sped-up sections could stop partway through export and never finish. The application also now tells the user when export stops making progress. That matters when a tutorial compresses a long demonstration into a shorter sequence. The release does not quantify the number of affected projects or claim a faster render. Nor does it establish resumable export. A clearer stalled state helps someone decide to intervene instead of interpreting an unchanged progress indicator as normal work.

[S01]

Automatic edits remain editable

The product combines recording and editing rather than asking the creator to move a recording into another application. After importing or capturing footage, the user explicitly invokes Auto-Polish and can revise its results on a timeline. The current site treats caption creation as a separate action, so older launch copy should not be used to imply that every automatic polish also produces subtitles. For a spoken tutorial, the remaining editorial task is concrete: listen to transitions and decide whether a pause carries meaning. Removing hesitation is useful only when it preserves the intended explanation; a cleaner waveform is not itself evidence of a clearer lesson.

[S02]

Local footage does not make every feature offline

Local processing is a useful distinction for recorded material, but it needs a narrow reading. The vendor describes network exceptions for typed AI Assistant requests made with the user’s own API key, stock-media retrieval, and certain initial language-model downloads. Those are different data paths from uploading a whole video for editing. No independent privacy test was performed here. The advertised project-file handoff between iPhone and Mac can support work across devices, but the supported systems still matter: macOS 14 or later and iOS 18 or later. Creators should also retain their original footage when moving a project, rather than treating a successful handoff as a backup strategy.

[S02]

Check the deliverable before the license

The free editor includes AI tools and no watermark, but limits exports to two minutes and 1080p. The website lists a one-time Pro price of $89 for Mac and iPhone with updates within version 1.x; the checkout currency was not independently established here. That should not be described as every future major release being included. Paid export options become relevant for longer tutorials or delivery requirements beyond the free limits. For a short clip, the free route can reveal whether the workflow suits the creator before purchase. The adjacent November 6 releases changed store listings only, so they are not additional editing features in this update.
