Select the scope before requesting a change

Inherited motion projects often create work through unclear naming, composition dependencies and broken expressions. The assistant accepts requests within the open project. Selecting layers, compositions or folders provides a bounded scope for organization; selecting a property gives an expression request a concrete target. Without a selection, an organization request may concern the whole project. That makes scope part of the interaction rather than an incidental detail. The assistant can remove some menu navigation and short-script work, while the designer still decides which naming and grouping conventions will help the next person maintain the file. A tidy-looking project is only useful if its structure still matches the production.

This is a rollout, not the assistant’s first appearance

Adobe’s community announcement dates the staged 27.0 rollout to November 7 at 05:15 UTC. Visibility in Creative Cloud can differ across users. The assistant was already available in beta, so the new event is the shipping rollout rather than the invention of the feature. Other announced changes include converting Illustrator text into editable text layers and using layers as material sources for 3D objects. These details matter when later revisions need to preserve structure. Adobe says fuller release materials will arrive on November 10. Unpublished terms or limitations should remain unresolved rather than being filled in from assumptions about earlier beta access.

[S20]

Undo does not roll back the entire request at once

The default permission behavior asks before actions, and settings also allow automatic approval. Changes to layers, keyframes and expressions can generally be edited manually, but one natural-language request may produce several operations. Undo steps back through those operations individually. Recovering from a request that both renames items and alters expressions therefore requires understanding what changed. Generated images or video are a separate case: they enter the project as media, not as native animation layers and keyframes that can be adjusted in the same way. That difference is particularly relevant when a client expects repeated revisions after approving the first visual result.

Reusable instructions still need a result check

Existing custom skills can preserve organization preferences and repeatable checks as files invoked through the assistant. Adobe’s earlier examples include text checking and project preflight; these are supporting workflow context, not newly introduced features of this announcement. Reuse saves repeated explanation, but an old instruction can also carry an unsuitable convention into a new project. Reviewing media references, fonts, expressions and composition settings remains necessary before inspecting representative output frames. The announcement’s visible discussion includes a user asking about a color-space and blending issue, with staff checking rather than confirming a fix. That exchange does not establish either a resolved defect or its prevalence in the new version.
