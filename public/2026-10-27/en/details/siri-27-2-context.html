Siri 27.2 recalls earlier answers and adds a shared control for excluded apps

A second search can start from the earlier answer

A person who asked about restaurants last week may remember only “the place you suggested,” rather than its name or the original wording. iOS 27.2 explicitly adds recall of previous Siri conversations. The input can refer back to an interaction instead of rebuilding a complete set of search terms. That continuity can reduce repeated explanation, but it introduces a time problem: restaurant information, an earlier free afternoon or a cancelled plan does not remain current simply because it was remembered. The interface needs to help people distinguish a recalled answer from a fresh check. Otherwise a useful memory feature can look like confirmation of information that has already changed.

More sources make exclusions more useful

The update broadens usable personal context to include message attachments, calendar attendees and voicemail, alongside an Excluded Apps control. Someone trying to find material from a particular person may no longer need to remember which application contained it before searching. The opposite need is equally concrete: a work or personal application may be inappropriate for suggestions. A shared exclusion setting makes that choice easier to locate, but it should not be understood as deleting the original application’s data. Access for retrieval and suggestions is separate from where a source record is stored. That distinction matters when people later change the boundary or try to understand why an answer omitted something.

Language support and regional access are separate

Apple’s October 26 announcement confirms five additional languages alongside the existing English support. Traditional Chinese, Norwegian, Turkish and Vietnamese remain planned for later in the year. The broader Apple Intelligence language list is not the Siri AI availability list. On iPhone, the support page excludes the EU and mainland China and requires compatible hardware. Family members using different devices and languages may therefore see different options even after installing the same system version. Checking device, language and region before expecting the feature is more useful than presenting a software update as universal access. This is an availability expansion and context update, not the first appearance of Siri AI.

Less context reconstruction, with decisions still visible

No new sensor is disclosed for this update; the change concerns retrieval, remembered interaction and access controls. After a voice or text request, people still need to inspect the context found and decide how to use it. Drafting an email and sending it are different actions, as are finding photographs and sharing them with a recipient. Some server-side features have daily limits, and expanded access is planned to become paid; no complete price supports a cost-per-task calculation here. Ordinary system search remains a direct alternative for simple lookup. Continuing conversations become more useful when the same question repeatedly depends on context scattered across applications.
