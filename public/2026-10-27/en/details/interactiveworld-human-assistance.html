Instructions that change the next observation

Watching a fixed video and answering a question cannot reveal how a mistaken instruction changes the next step. InteractiveWorld puts guidance inside a changing simulated scene. An assistant observes a first-person image and speaks; another model interprets the advice as a person and performs actions; the environment returns a new observation. The relevant product question concerns cooperation between instructions and actions, rather than robotic joint control. An assistant that sounds clear may still direct the wrong sequence. A test that preserves those consequences gives a designer something concrete to investigate when the final outcome fails, while remaining distinct from a deployed household assistant.

Checking state rather than the closing summary

InteractiveBench contains 120 tasks divided among guidance, planning, accessibility, decision, prevention and finding. State checks distinguish a completed action from a summary merely claiming completion. The repository exposes thirty-six action families and task material for inspecting failures. Its current README lists forty-four admitted scenes, while the paper describes fifty; those should not be merged into one claim about the delivered version. Running the environment requires Linux and NVIDIA hardware, with substantial storage and asset preparation. For a research team, this creates a repeatable investigation tool. It is not equivalent to launching an end-user assistant in a browser without setup.

The executor is part of the measurement

Across twelve evaluated models, the best overall completion rate is 41.7 percent; the best guidance and planning results are twenty and twenty-five percent. Three human executors also performed a limited subset inside the simulator. This checks part of the dependence on the model playing the person, without establishing performance across actual users or homes. People may hesitate, misunderstand, skip a step or ask an unforeseen question. For a product team, distinguishing perception errors from unclear instructions and execution misunderstandings would be more actionable than a single ranking. Each category requires different remedies, and the surrounding sequence matters when assigning responsibility for a failed outcome.

Keeping setup and task boundaries visible

The repository uses a noncommercial license, and body and motion assets have separate registration and licensing conditions. Public access is therefore not unrestricted commercial reuse. This report did not run the environment. A focused evaluation could test how the assistant describes grasping an object and revises advice after its position changes. If guidance succeeds only with the simulator’s fixed vocabulary, that is a reason to investigate transfer rather than assume it. Real people, objects and ability differences remain necessary for deployment validation. The present contribution is a reproducible way to observe sequential guidance failures; reduced effort in a target activity remains a separate outcome to demonstrate. Licensing and setup effort should therefore enter the evaluation alongside the reported model completion rates.
