Making the behavior available to try

A static mockup can show the appearance of a filter without making its empty results, reset behavior or repeated use easy to evaluate. Replica places a running prototype in a canvas beside the GitHub Copilot conversation that changes it. A teammate describes the behavior to explore, while the supplied components, patterns and documentation guide the generated application. Subsequent requests refine something people can actually try. The October 28 event is the open-source release of this tool, separate from Copilot’s project-management features. Teams still need to specify sample data and meaningful states: a page opening successfully does not establish that the proposed interaction handles the conditions of the real product.

Trying the canvas before arranging hosting

The local route starts from Minimal, CoreAI Sandbox or an existing prototype repository. Minimal keeps the example small; CoreAI includes a navigation layout and Microsoft interface elements. The documented canvas workflow requires macOS or Linux, Git, Node.js with npm, and a signed-in Copilot app. Model access can use a Copilot plan or the preview option for a separate provider. The plugin and its canvas have separate switches, followed by a fresh session. After the agent starts the development server, the user connects the preview and tests it. A Hub, domain and remote GitHub repository are unnecessary at this stage; opening a local project does not itself publish anything.

Turning design guidance into reviewable input

Using the team’s design system means more than selecting a brand name. The local guide asks users to run setup-skills and supply approved product documentation, design references and component or token packages. Copilot drafts guidance, which a person reviews before separately approving its application. This distinguishes finding material from adopting it as the instructions for future work. Without that input, the starter remains useful for experimentation but does not establish conformity with the team’s system. A concrete task such as a searchable project list can include empty results and clearing the search. Keeping guidance aligned with component upgrades and actual product behavior remains an ongoing responsibility for the team.

Sharing introduces another operating responsibility

Sharing a link for colleagues to explore and comment requires the optional Replica Hub. The repository lists a Linux server, dedicated domain, wildcard DNS, HTTPS, network access and GitHub permissions as prerequisites. Local work can continue while those are arranged, then connect the same repository later. Viewing a finished prototype or reviewing it in Hub does not require a Copilot subscription, but hosting and model consumption remain separate costs. The organization configures Hub; publishing and review events stay in its database for 90 days, with external analytics requiring administrator configuration. Those events do not measure local editing or interactions within previews. Self-hosting Hub also does not remove the separate data handling of GitHub and the chosen model provider.
