Turn a mark on the page into an editable location

Papilot addresses a specific revision problem: an author notices something in a PDF, searches for its LaTeX source, asks an agent to edit it, then recompiles and compares the result. The workspace lets the reader select a sentence or mark the region containing an equation or figure and add a request. SyncTeX mappings produced during compilation connect page locations to source files and lines, which accompany the note sent to the agent. Equations can therefore reach the task as LaTeX rather than imperfect extracted text. This depends on a compilable source project and its mappings. It is not a promise to reconstruct an arbitrary scanned PDF into an editable original.

Group related feedback before starting a task

Version 0.7 collects PDF notes, group instructions, skills, attachments and the revision prompt in one task composer. Readers can assign related notes a color, write one instruction for the group and send individual notes or the whole group. Unsent notes remain available for another round. This fits changes such as making terminology consistent across a paper or aligning notation in several equations without repeating the same background for each location. Files and images can accompany a new task or follow-up message. After recompilation, notes are relocated when possible; uncertain positions are flagged rather than silently attached elsewhere. Grouping organizes feedback, but does not establish that the model understood every passage’s different context.

[S11]

Review first, then choose the destination

After the agent edits, Papilot builds a typeset comparison for accepting, rejecting or commenting on changes. Related effects, including equation renumbering and contents changes, can be inspected alongside the edit. Version 0.7 changes delivery for new tasks: accepted edits stay in the task worktree until review is complete. The user then applies them to the working directory or commits them to a separate papilot branch. The agent drafts a commit message that remains editable. Existing tasks retain their previous delivery behavior, so an upgrade does not retroactively isolate every task. This provides a deliberate handoff point for a revision round, while leaving authors responsible for whether the changed argument is actually correct.

A local workspace still needs an agent and a compiler

Papilot is published free under MIT, but running it requires Node.js22.22 or later, Git and a complete TeX distribution; revisions also need an available agent account. The version 0.7 material names Codex, Claude and Antigravity. New integrations and bibliography checks on the current development branch are outside this released-version account. Importing a LaTeX folder or ZIP identifies the main document and compiler, prepares Git history and attempts a build. Compilation failures still require repair. A supplied 26-page example with equations is useful for exploration but cannot validate a user’s complex template. Browser controls do not remove TeX dependencies, model quotas or maintenance work, and free software does not make generation requests free.
