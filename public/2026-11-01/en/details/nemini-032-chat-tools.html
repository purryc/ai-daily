Generated tools remain usable in the conversation

Version 0.3.2 adds small applications such as trackers, countdowns and games inside Nemini’s conversation, with the maker saying they remember where the user stopped. A person describes a useful tool and continues interacting with its output rather than receiving only instructions to implement elsewhere. Charts and tables can also present habits, spending or mood in a reply. That can remove copying between chat and a separate organizer. The October 31 changelog supplies a version and date, but no clock or timezone, so it is a recent supplement rather than a confidently timed main-window event. Editing limits and recovery from failed persistence are not detailed.

Making completion something the user reviews

The new shared list gives the user and companion a common task surface, with completed work handed back for inspection. It creates a useful distinction between work in progress, the agent considering it complete and the person checking the outcome. The existing service includes a sandboxed browser, code runner and accessible file desk, so an outcome may be a document, spreadsheet or page rather than a chat message. The announcement does not specify acceptance rules for every task or demonstrate automatic correctness checking. The review item is best understood as a return point to inspect the actual file, calculation or page before accepting the result.

Memory can generate a quiz and still be wrong

Quiz cards draw questions from the companion’s memory and conceal answers until the user responds. Quoting selected words from a reply also gives follow-up questions a precise target. The previous day’s version 0.3.1 introduced importing earlier chats, with the user choosing whose words they represent. Together these features make prior conversation reusable for learning and ongoing work. They also make provenance consequential: something the user said, an earlier assistant response and a later summary are different kinds of evidence. The release does not say quizzes verify every answer against original material. Concealment improves the answering interaction without establishing factual accuracy. The same release also reports a speaker-call fix for replies stopping after a sentence or two. The note gives no device matrix or independently observed call-continuity result.

Persistent memory is hosted data

Nemini remains in early access with seats opening gradually. Its policy describes memory beyond a transcript: extracted facts, summaries, graph entries and embeddings, alongside uploaded files and browser artifacts on the companion’s machine. Processing is hosted, with some requests eligible for outside providers; bringing a personal API key applies that provider’s terms. Settings offer export, reset and deletion. The policy gives up to thirty days for personal-data deletion, with backup copies expiring separately. Publishing is off by default, but media addresses can be opened by anyone holding the link. Importing an old chat therefore deserves a choice about what should enter persistent memory.
