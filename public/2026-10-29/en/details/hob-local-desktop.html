A persistent place to work with files

Hob starts with files and projects rather than only a blank conversation. A user can attach a sales workbook, ask for a regional chart, and follow up about a particular month. Project folders keep related material and instructions together. The repository’s screenshot shows the spreadsheet attachment, an interactive revenue chart, a PNG download and other tasks in the same project. The application supports Mac, Windows and Linux under an MIT license. Its October 28 Product Hunt appearance and same-day 0.2.4 and 0.2.5 releases establish recent activity. Those release entries do not explain every incremental change, so the full documented feature list should not be presented as newly added on that date.

Model selection becomes part of setup

Setup checks the hardware and downloads a model from the maintainers’ curated open-weight selection. The documentation distinguishes smaller configurations from larger models and uses llama.cpp with Metal on Mac or CUDA and Vulkan elsewhere. Spreadsheet requests can invoke Python and established data or document libraries, rather than requiring the language model to invent arithmetic. Image understanding downloads a separate vision model. This packaging removes several setup decisions: which model to choose, how to run it and how to provide basic file tools. Storage, memory and execution time remain the user’s responsibility. Loading a model successfully is not evidence that a long task will finish promptly or that a complicated workbook will be interpreted correctly.

[S08]

Local inference does not erase online boundaries

According to the documentation, chats and files remain on the machine, edits require confirmation, Python execution is confined to the chat’s folder and tasks have undo. Web access adds online search, data retrieval and installation of Python packages. User-added MCP connectors also have their own network connections. Offline use therefore requires inspecting those settings, not merely noticing that inference is local. Plugins can preserve the steps and code from a successful task as a reusable skill, with a review before saving. That could help with recurring spreadsheet cleanup. Reuse still needs a check against the next file’s structure: yesterday’s column names and transformation rules may be wrong for today’s export.

[S08]

The trial costs machine resources and review time

There is no account or subscription charge, but the models consume several gigabytes. Removing the executable does not always remove those downloads. The documentation recommends the in-app removal command; on Mac, dragging the application to the Trash leaves model data behind, while created documents are retained separately. This helps people estimate both installation and exit costs. A practical trial uses a copy of a familiar file: calculate totals, create a chart, verify that the original is unchanged and inspect what remains after undo. Waiting and reviewing may outweigh the manual steps saved. No independent speed, accuracy or recovery measurement was established here, so the free license cannot substitute for that comparison.
