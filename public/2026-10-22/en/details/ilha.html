Observe before interruption

ilha places coding-tool allowances beside the Mac notch, using a small pill on other displays. It targets people who work with accounts for Claude Code, Codex or Grok Build and want to see shorter and weekly limits before an interruption. The existing workflow often begins after work stops: open another page, inspect usage and determine which account can continue. This utility moves that inspection earlier. It was discovered through the October 21 launch board, but official terms and privacy material already carry October 17 and 18 dates. This is a lookback, not proof that the software first became available on the listing date.

Credentials and continuation are separate

The website presents warnings near a limit and automatic switching, but the maker’s public reply adds an important qualification. Running Claude Code sessions can follow the change, whereas existing Codex sessions need restarting after a switch. Continuing to code should therefore mean less work locating an available account, not guaranteed migration of every running state. A user also needs an understandable indication of the active account and a way to recognize an unintended choice. Those are acceptance questions, not tested behavior here. No account was switched, and continuity of context or artifacts during an interrupted task was not verified.

Local data still has access details

The privacy page says usage, session logs and login information are not sent to the seller, and it describes Keychain storage for credential copies. It also documents a qualification: programs using the macOS security tool may read those copies, and the choices in a Codex permission prompt have different consequences. The Keychain label alone does not mean every access asks again. Anonymous counts and crash reports are on by default but can be disabled; updates and Pro licensing also make requests. Adoption should examine credential access, diagnostic traffic and the model provider separately, instead of interpreting unuploaded usage data as no external communication at all.

[S63]

Measure interruptions, not estimated savings

The free tier watches the account currently used by each CLI, and the first launch offers a fourteen-day Pro trial. A one-Mac Pro license is US$20 plus applicable tax, with one year of updates; versions released during that period retain Pro afterward. Insights values local activity at API rates, which is neither the subscription bill nor demonstrated savings. Provider usage pages, other menu-bar tools and manual checking remain alternatives. A falsifiable pilot measures interrupted tasks, switching and restart time, wrong-account use and repairs. More visible forecasts do not justify adoption if people still reconstruct tasks or spend the saved time managing additional access boundaries. Successful switching should be recorded separately from the later completion of the original development task.
