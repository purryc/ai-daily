Sharing activity, not just results

Literature collaboration often begins only after someone finds a result: a researcher forwards a link, while colleagues cannot see the queries already tried or why a paper was rejected. Scriptorium adds workspaces, shared chat and an attributed activity timeline to a conventional search-results page. Queries, saves, openings and soft deletions correspond to actual system events. Removed papers remain visible with a struck-through state, preserving abandoned directions as evidence. The intended job is collaborative exploration of a topic. Reduced duplicate searching and connections between research threads are hypotheses for a planned user study, not measured benefits. The October 20 technical-report submission is a three-day supplement, not a commercial service launch.

Scope each agent’s evidence

A manager routes work among seven specialized agents. People can name an agent directly or use @ai for routing. The summarizer requires attached documents; method and citation agents can use attachments or saved material; the collaborator-bridging agent sees each person’s queries and titles. Query reformulation excludes abstracts and chat, while other eligible roles retain at most eight recent chat turns. This makes the evidence scope inspectable instead of sending every workspace field indiscriminately. Deterministic preflight checks reject missing inputs. Direct invocation generally uses one model call and manager routing two. The reported default is gpt-5, with model usage billed to the configured account.

Implementation sets the adoption boundary

Retrieval uses an institution’s Ex Libris Primo service, so results depend on its collection and licensing rather than being identical across deployments. React, Express and MongoDB maintain shared state; chat and timelines poll every three seconds. A mock provider without an API key is a development stub, not working AI. More consequentially, the authors disclose no signed session token: backend endpoints trust a client-supplied user identifier, and logged-in users can inspect all workspaces. That can support a controlled study with informed participants, but it is not tenant isolation. The paper names an MIT-licensed repository; its supplied GitHub URL returned 404 here, leaving code access and reproducible deployment unverified.

Evaluate collaboration rather than agent count

Alternatives remain reference managers, shared spreadsheets, chat and manual search logs. Scriptorium’s distinctive hypothesis is that scoped agents can use discarded material and collaborators’ activity to help the group, at the cost of visibility choices, model-data disclosure, institutional integration and workspace maintenance. A small comparison should give the same team comparable search tasks and measure duplicate queries, missed relevant work, useful cross-topic connections and review time. Incorrect summaries should be traceable to their permitted evidence. If visibility mainly creates surveillance concerns or explanation overhead, additional agents have not improved collaboration. Production use also needs authentication and enforced workspace boundaries; an owner label in the interface cannot establish either.
