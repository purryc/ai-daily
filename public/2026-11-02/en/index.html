Ideogram confines edits to a window without shrinking the whole image

For a small change in a product or interior photograph, Precise Edit takes the original image, an instruction and a selected area.

A context window selects the working region; a mask can narrow the change within it. The response is the full-size image. The window can follow the mask or use coordinates, retaining surrounding material and lighting references.

Recoloring, object removal and label repair can avoid a separate crop-and-paste workflow. The vendor says pixels outside the window remain unchanged.

Automatic windows require a mask; an oversized selection can fall back to a downscaled whole-image edit. Boundaries and reflections still need inspection; exact cost is unverified. A dry-run API request can quote an edit without generating it.

Product perspective

November 1 marks its PH presentation, not Ideogram4.5’s debut. Preserving resolution does not establish correct lettering or materials.

Nesformer runs scripted NES games through compiled model weights

Nesformer lets curious developers supply a compatible game ROM and a frame-based button script, then view frames and save a GIF.

A compiler calculates Qwen3.5-shaped weights that emit CPU traces token by token; a host handles graphics, controls and timing.

It does not train a model to guess game pictures. The same weights load different NROM games and support stepwise reference comparisons. The output is a traceable instruction sequence, not an agent learning to win.

Python is required. Cartridge and instruction support are limited, audio is absent, and the author reports operation 150–290 times slower than an NES.

Product perspective

Useful for inspecting deterministic computation inside model architecture, with conventional emulators remaining the practical alternative. Publicly reported October 30; a lookback.

TouchBridge records fingertip contact to make human demonstrations usable by robots

TouchBridge targets robotics teams collecting demonstrations of contact-sensitive tasks such as page turning and bulb screwing.

Cameras, hand tracking and fingertip sensors record the demonstration, which is converted into robot observations and actions for policy training. Corresponding camera and fingertip layouts connect the human capture setup with the robot.

The transfer aligns contact patches and relationships between fingers, rather than matching pose alone. Conversion does not require an object mesh or physical simulation.

Touch is used during data conversion, not as an online policy input in these experiments. Sensors, calibration and training remain necessary; this is not a consumer product.

Product perspective

The authors report 72.5% average success across four real-robot tasks, versus 77.5% with teleoperated data. Sevenfold faster collection is not sevenfold faster end-to-end training.
