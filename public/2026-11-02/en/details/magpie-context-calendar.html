Selection carries the context into the next action

An event email often creates a small copying routine: take the title to Calendar, return for the start and end times, then retrieve the original link. Magpie places its entry point beside selected text. Its floating bar offers translation, explanation and summaries, alongside actions for dates, places and email addresses. The October 28 release adds model-assisted contextual extraction for date ranges, isolated times and event titles. Calendar preparation also carries the source page, the selected passage as notes and detected email invitees. These are prefilled fields for review. The release does not establish autonomous invitation sending or correct interpretation of every ambiguous expression of time.

A simple recognizer remains available

Users configure a model and enable intelligent extraction. When the AI finds no entity, the application falls back to built-in recognition; the switch can also be turned off, and the prompt edited or reset. That is a useful control for someone repeatedly processing similar invitations without rewriting a complete instruction each time. Provider presets and OpenAI-compatible interfaces offer a choice of backends, but the selected provider still handles the request. Open-source application code does not make every model call free, and recognizing a date does not prove that a calendar entry was saved. Useful checks include month boundaries, a bare three o’clock, quoted historical dates and passages containing several unrelated email addresses.

System selection and cloud processing have separate boundaries

On macOS, system events and Accessibility interfaces supply selected text; Windows uses mouse hooks and UI Automation. Some applications require compatibility handling, and elevated windows can be inaccessible. An application blacklist helps avoid accidental triggers in terminals or password managers. Local OCR is a separate fact from the handling of translation and model requests: selected text can leave the computer for the configured provider. Documentation also says API keys currently remain in a plaintext local settings file, with system-keychain migration planned. An organization therefore needs to consider triggering applications, permitted text transfers and protection of the local account and configuration, rather than relying on the desktop label alone.

The two recent releases address different problems

Version 0.1.19, published November 1, fixes a different problem: two floating actions could both retain their pressed highlight after a quick pointer sweep. Only the hovered action should remain highlighted, including when menus open or close. That improves selection feedback; it is not the launch of contextual calendar extraction. The latter belongs to October 28 version 0.1.18 and is included here as a seven-day lookback. Compared with built-in data detectors or manual copying, Magpie preserves more source context and permits an adjustable model interpretation. The additional costs are a model request and the possibility of accepting a wrong prefilled field. A useful trial checks fewer copying steps alongside correct provenance and participants.
