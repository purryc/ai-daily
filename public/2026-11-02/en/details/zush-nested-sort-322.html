Review the name and destination together

A conventional batch renamer can add the same date or prefix to many scans. Filing by the company and month visible inside each document usually requires opening every file. Zush combines content analysis with a naming template and presents proposed names and destinations for review. Existing folders can be reused, helping subsequent batches fit a maintained structure. The useful labor reduction is repeated inspection, typing and dragging. A person still has to decide whether an extracted date means issue date or payment date. A tidy directory can conceal a semantic mistake, so inspection should include representative document contents rather than only checking whether the resulting names look consistent.

This update addresses folder depth and write timing

The Mac changelog dates version 3.22.0 October 31 without a clock or timezone. Its relevant changes concern following rules through the complete folder hierarchy, preserving specified folder names, and waiting for an image to finish saving before Monitor renames it. The last detail matters in folders receiving screenshots or downloads: a newly visible file may still be incomplete. Hierarchy handling matters when a filing scheme combines client, project, year and month. These are published fixes, not independently measured success rates. The Mac release also does not establish an identical Windows release on that date. Folder sorting itself predates this version; this is a reliability update to an existing workflow.

[S01]

Local files can still produce cloud requests

Zush offers managed cloud analysis, user-supplied provider keys and local models. Its privacy policy describes cloud payloads that can include previews, extracted text, audio or video context, and naming instructions. Keeping the original file on disk does not keep every representation of its contents there. Supported local analysis uses an on-device model, while licensing and update checks can still contact backend services. The decision concerns what this collection may send to a provider. A personal photo archive and confidential client documents may require different settings even when the same desktop application handles both. These are documented processing boundaries rather than an independent privacy audit.

[S03]

Test a filing rule on copies first

The pricing page lists fifty free renames in total, then $10 monthly or $48 once, plus VAT. The inspected section uses a dollar sign without explicitly resolving the currency, so those amounts should not be converted into a local quote. A useful trial takes copies of a small, ambiguous collection and compares correction time with manual filing. It should also check whether undo restores the intended paths. The sorting documentation cautions against moving files referenced by other applications. A reusable template may remain helpful when many exceptions exist, but that does not justify immediately assigning every incoming file to unattended monitoring.
