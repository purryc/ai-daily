Pointing instead of describing the whole screen

Writing a polite refusal to an email often means copying the message into a chat tool and bringing the draft back. sideOS places a voice entry point at the Mac notch and lets the person frame an object while speaking. It combines accessibility information with images where needed, then uses actions such as clicking, typing and AppleScript. A request can therefore refer to the current screen without a long verbal description. That convenience still depends on the correct window and target remaining in focus. Dictation has its own shortcut and writes at the caret, keeping a simple text-entry job separate from a task that requires model reasoning and application control.

What the October update actually adds

The October 24 release history identifies version 0.9.8 as an expansion of the local model catalogue. Newly added Gemma and Ministral options can also interpret screenshots and image attachments. That gives visual tasks more local choices; it does not mean that the largest model will run comfortably on every supported Mac. A chart or drawing surface may carry information that a text-oriented accessibility tree cannot describe, which explains the practical role of vision support. Model downloads, memory requirements and response time remain part of the experience. There is no published task-by-task comparison here establishing which option is best. The same-day Product Hunt appearance is a discovery event, not the application’s first release.

Local storage and outgoing requests are separate

The privacy policy distinguishes default on-device speech recognition and local records from requests to a chosen cloud provider. Relevant screen content can accompany a cloud request; optional voice services and MCP connections have their own exchanges. Anonymous daily statistics can be disabled. A manually submitted problem report can include instructions and dictated text in the current session log, which the user can inspect before sending. These distinctions matter for an assistant that sees other applications: choosing a local model is only one configuration decision. Someone handling confidential material also needs to consider connected services and support reports. The policy documents those paths; it is not an independent network-traffic audit.

[S12]

A purchased app still needs model and permission choices

The site requires Apple Silicon and macOS 14 or later and lists a one-time $89.90 price without identifying the currency. The licence covers one Mac at a time, can move between machines and includes future app updates; cloud model use is billed separately. Local inference also needs to be distinguished from licence operation: the terms allow up to thirty days offline after renewal. A person considering the app must decide whether configuring models, permissions and connections is worthwhile for their recurring work, or whether ordinary dictation and manual actions already suffice. Draft entry is useful, but important sends, deletions and purchases still need checking. The ability to click a control is not evidence that it selected the intended one.
