Make the first picture the edit target

A designer supplies the picture to change first, followed by visual references and a written request. The model’s prompt expansion describes what to retain and which reference supplies a detail. This ordering matters: putting a reference first can target the wrong image. The vendor demonstrates eight portraits combined into a dinner scene, without independently establishing reliable identity preservation. The launch introduction says nine inputs, while the model cards consistently specify eight. Eight is the documented conservative limit here. A useful review compares the requested alteration with everything that should have stayed unchanged, rather than accepting a coherent-looking composition as proof that the instruction was followed.

Inspect the expanded instruction

A short instruction can leave preservation requirements unstated. The vendor’s comparison shows unwanted redrawing when those requirements are absent. The pipeline can return its expanded instruction, giving reviewers something concrete to inspect before trusting the result. For a team, saving the request, expansion and output helps distinguish interpretation mistakes from rendering mistakes. Pruna adapts a video foundation model for still images through a revised decoder, shorter sampling and compressed components. That does not make this a video generator. Comparison with another editor should use the same requested change, resolution and tolerance for unintended alterations; a selected attractive image cannot establish repeatable editing quality.

Read memory figures with their configuration

The smallest ComfyUI base download is about 20 GB, with a separate prompt model still required. The reported 21 GB peak belongs to that optimized configuration. The full Diffusers setup reports roughly 101 GB with prompt expansion, so the numbers cannot describe one interchangeable installation. ComfyUI support currently requires its main development branch; desktop and cloud clients await a stable release. Buyers should budget the complete component set and test their intended machine. Smaller weights can also change details or composition. For an asset library that depends on visual consistency, those differences may cost additional review and rework even when the configuration fits cheaper hardware.

Open weights carry territorial and commercial conditions

The November 3 release belongs to the recent supplement. Its MiniMax H3 community license excludes the US, UK, EU and South Korea from the ordinary territorial grant and describes a separate licensing route. Commercial interfaces must display MiniMax H3; further commercial conditions apply. Calling this unrestricted open source would conceal a material adoption constraint. Distribution geography therefore matters alongside memory and image quality. For production artwork, manually typesetting labels and body copy remains sensible because dense text and small visual details can fail. No model execution, independent speed measurement or memory benchmark was performed here. An editing trial should include unwanted changes and correction time, not only render latency.
