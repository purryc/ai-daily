A task can keep its own working interface

MiniMax’s October 22 introduction presents Mini Apps as small applications with an interface and a persistent backend. A page can sit beside a conversation or open in its own window. Users can install an existing app or ask the Agent to create one. The practical idea is to remove repeatedly edited work from a pile of chat history: return to the itinerary, list or model and continue changing it there. The October 17 changelog already mentions Mini Apps and Bot, so this is an introduction and expansion of the format, not evidence that the capability first became available on October 22. Our assessment is that changing, revisited tasks benefit most; a one-off question may not need its own application.

Point at the part you want changed

CadQuery Viewer offers a concrete example. It lists models in the current conversation’s working folder, lets the user open and rotate them, and records points on their surfaces with written instructions. Part names and coordinates can then return to the conversation. Someone designing a desktop stand could identify the screen, upright and base separately, asking for a hole or a changed angle without describing “the piece on the left” in several sentences. The developer’s supplied screenshot shows this multi-point interaction. Its documentation distinguishes STL from STEP support; preserving assembly information with STEP requires an additional Python and CadQuery environment. In our reading, spatial pointing reduces ambiguity in the request. It does not by itself prove printability, fit or structural strength.

A road-trip app keeps places, routes and saved plans together

The road-trip plugin brings place search, route alternatives and saved trips into one interface, with a demonstration mode. Its repository documentation says real Amap queries require user configuration, while trips persist in a local database. Optional Xiaohongshu functionality has separate service and login requirements. These details change what the user actually has: seeing a demonstration without a configured map service is not receiving live road information. For someone comparing stops before a weekend drive, a persistent page could be easier to revisit than itinerary prose repeatedly displaced by new answers. Our interpretation is that changing stops and asking the Agent to explain trade-offs is a natural collaboration. The freshness of roads and opening information still depends on connected data.

Persistence still belongs to the local desktop

Official documentation limits Mini Apps to local sessions in the macOS and Windows desktop application. Cloud, SSH and remote-control sessions do not start them on the user’s machine. When a page hands content to the Agent, it enters the message input for editing and confirmation. The host manages runtime services and declared permissions, but plugin code still executes as the local user; protected credentials do not mean an app has no local access. Individual features can also add costs: the Viewer’s image rendering is billed as ordinary image generation. Our judgment is that the format is a customisable personal desktop workspace, especially for creative work and everyday planning. It should not be mistaken for an already deployed shared website. We did not install or run the plugins.
