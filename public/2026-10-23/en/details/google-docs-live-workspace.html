Workspace availability is the new event

Google’s October 21 release note makes Docs Live available to eligible Workspace users on Android and iOS, including Business Standard and Plus and Enterprise Standard and Plus. This is an availability expansion, presented here as a three-day supplement. The September 3 announcement had already introduced the same feature to Google AI Pro and Ultra consumers while saying business access would follow. For someone who uses both personal and organizational accounts, the meaningful change is being able to build a mobile draft alongside the relevant account’s documents and communications. It should not be counted as a newly invented voice-writing tool or a first consumer launch.

Speak the intent, adjust the plan, then draft

The documented flow is more structured than transcription. In the Android Docs app, the user opens the create menu and selects Create with voice, then describes the intended document. Gemini first generates a plan. The person can remove a topic or add a section before tapping Next or saying “Show me the draft.” Further voice requests can change sections, organization or formatting, and Done finishes document creation. An event organizer, for example, could settle the outline around attendance, timing and responsibilities before expanding the prose. That example illustrates the interaction benefit: the user has a relatively small structure to correct before reviewing a much longer generated document.

Source choices give the spoken request its context

The mobile source settings allow a person to add a Drive file and choose relevant search locations across Drive, Gmail, Chat and the web. The broader Workspace source guide says added Drive files require viewing permission and remain active through the conversation. To exclude a source from an earlier turn, the guide instructs the user to start a new conversation and choose the desired sources again. That has a practical consequence when a person changes topics: an earlier event’s notes should not be assumed to vanish simply because the next spoken request concerns a different event. Source selection remains part of authorship even when the words arrive by voice.

Useful for fresh ideas, within mobile and English limits

The help page currently limits this workflow to mobile devices and English and requires an eligible Workspace or Google AI plan. The launch suggests using it while ideas are still fresh after a meeting or during a commute. Editorially, the intermediate plan is the distinctive feature: it creates a chance to notice missing topics earlier than a workflow that records speech first and organizes everything later. Mobile conversation is particularly suited to obtaining an editable first structure, while detailed layout work may still be easier at a larger screen. Google’s source guide also notes processing limits and potentially incorrect citations. The useful output is a draft with intelligible source boundaries, not merely a polished-sounding answer.
