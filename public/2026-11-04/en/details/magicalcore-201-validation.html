Start with examples for each class

A personal plant classifier can begin with a folder for each plant, using the folder names as labels. Other supported tasks need different evidence: rows in a CSV for tabular prediction, or short videos for hand movements. MagicaLCore brings preparation, training and trial use onto one iPad before exporting a model for Swift Playgrounds or Xcode. The practical attraction is a short feedback loop: collect examples, see what the model learned, then try another input. The user still defines useful categories and builds the interface that will eventually show a prediction to someone else. A model file is one component of that application, rather than a finished application by itself.

Keep the comparison consistent after a pause

The store notes describe a consistent validation sample after training resumes, together with export of the best-performing checkpoint. For a learner working between lessons, this matters because a changing evaluation set would make successive scores harder to compare. The pause transition also becomes explicit and temporarily locks controls. These changes make a session easier to understand, particularly when it cannot finish in one sitting. However, best means best against the validation material used for that session. It does not establish performance in another room, under different lighting or with an unfamiliar speaker. Those cases need deliberately separate examples and an actual trial.

Long sessions also need readable resource limits

The dated changelog addresses less glamorous interruptions: very large imports, external drives, the screen sleeping during a read, heat during training and misleading memory information. It also flags saved models that cannot open. These are useful distinctions on a device serving as both the dataset collector and training machine. A user needs to know whether work is progressing, waiting or failing before deciding to reduce a dataset or resume later. The release does not supply a universal dataset ceiling or completion time, and we did not measure battery use or throughput. Resource visibility improves the decision; it does not remove the hardware constraint.

[S35]

Local training and advertising are separate choices

The free edition covers all six model categories; Pro removes advertising and free-tier limits. The FAQ lists US prices of $4.99 monthly or $34.99 annually, with a separate lifetime option. Its stated requirement is an M1-or-later iPad on iPadOS 26, while the store compatibility field is broader, so the exact device deserves checking. The privacy policy distinguishes local training files from the advertising SDK’s information and optional personal iCloud model sync. Local model training therefore should not be read as a claim that the entire app sends no data. Allowing testing and export when an ad fails to load removes a particularly frustrating interruption at the end of an experiment.
