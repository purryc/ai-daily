Capture the task, then edit the explanation

When a colleague asks how to repeat a software task, the author can demonstrate it once in StepGrab. Selecting a window or display starts a sequence of click-linked screenshots that can be edited afterwards. The October 30 Product Hunt appearance is explicitly its second launch, highlighting Windows support, redaction and an editor; the earlier PH launch was in August. Capturing the task combines screenshot collection with numbered visual directions. The author still needs to remove exploratory clicks and explain business conditions that the interface cannot reveal. A complete click history and a complete explanation are different deliverables, especially when the same screen supports several valid choices.

Button labels come from different inputs

Projects now travel as a single file between Mac and Windows, allowing another computer to continue editing the same guide. An earlier maker forum post already describes these capabilities, so the new PH appearance should not be presented as the first Windows release. On Mac, the notarized direct download can use Accessibility permission to retrieve a clicked control’s name from the application. The App Store build instead reads text from the screenshot under its sandbox restrictions. That distinction affects the wording of instructions, not merely their appearance. Website licences cover the direct Mac build and Windows; the store build follows its own purchase route.

[S42]

A redacted export is different from a shareable project

The editor supports arrow adjustment, rewritten descriptions, marking and reordering, together with solid redaction boxes. Exported images incorporate those boxes, while an ordinary project retains original screenshots so the author can keep editing. Sharing an editable project therefore requires a separate Save As copy with redactions burned in. Another detail matters during review: a redacted step loses the element name from its suggested sentence, but manually written text remains unchanged. Someone preparing a customer guide should inspect both the image and its description. The application provides a way to remove the underlying pixels; choosing the right shared file remains part of the author’s workflow.

[S43]

AI is an optional wording pass

Capture and editing do not require uploading screenshots. Optional AI wording needs Pro, macOS 26 and enabled Apple Intelligence; the on-device model rewrites suggested sentences during export while retaining names, positions and click types. Windows does not offer that AI text feature. The free tier suits short guides and normally exports a marked GIF; more formats and exported step text require Pro. HTML lets recipients navigate a guide without installing StepGrab, while Markdown suits an existing documentation repository. Before sharing, a team should choose whether the recipient needs an editable project, a readable guide or a video, because those outputs serve different handoff tasks. This choice also determines whether later corrections require sending a replacement file.
