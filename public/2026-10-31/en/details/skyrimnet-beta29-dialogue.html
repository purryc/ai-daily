The selected line belongs to the player’s voice

Beta29 connects Skyrim’s dialogue menu to the player character’s configured voice. Selecting an option starts that spoken line before the NPC responds. A second click skips it; leaving the menu stops playback. The mod now handles this internally, removing the earlier DBVO setup step. Voice My Dialogue Choices is enabled by default and can be switched off. Existing DBVO installations still need attention because an active older plugin retains control of the menu. The useful change is continuity between free conversation and the game’s authored choices. It does not mean a language model has taken control of every quest decision.

A kitchen becomes usable context

Players can label a spot inside a building and manage its extent in the Places page. A room name then accompanies an actor’s location in prompts, events and memories. Labels can be renamed, moved, disabled or deleted and reused across playthroughs. This complements the existing perception system: characters respond to events they could plausibly witness, while whispering reduces the audience. The location comes from game state and player definitions. It is not a new camera sensing the real room around the computer. Users still curate boundaries, and customized event-history templates need the new location rule to avoid treating every line exchanged across rooms as another move.

Speech, memory and actions have separate jobs

The interaction has several distinct stages. Whisper or a configured service transcribes speech; a language model combines that text with character and game context; a speech engine voices the reply. Piper, the default local voice engine, runs on the CPU. Different jobs can use different models, so selecting actions need not share the same configuration as a long conversation. A local embedding model retrieves each character’s memories by meaning, with importance affecting decay. The chat overlay supports a named recipient, whispers and groups and shows who can hear the player. This separation offers useful control, but replacing the dialogue model alone cannot repair transcription, voice quality and action execution together.

[S02]

The mod still needs a configured game

SkyrimNet runs as an SKSE plugin inside the game. Installation still involves a mod manager, enabling the plugin and completing setup through the dashboard. Special Edition, Anniversary Edition and VR have their own dependency considerations. Integrated hosting reduces the work of configuring separate model and voice accounts; it does not install the game’s prerequisites. Beta29 adds nine interface languages, including Simplified Chinese, with machine translation and English fallback for missing strings. The public repository uses its own license: playing and personal modification are allowed, while redistribution is restricted. It therefore should not be described as open source. The audience remains players comfortable maintaining a modded game and checking how its characters actually behave.
