Release memory before starting the next job

A home workstation often needs a clearer handoff more than another model. A chat server can retain GPU memory just as its owner opens ComfyUI or a game. Manually finding the process, unloading weights and restarting the first service becomes part of the routine. Berth wraps engine starts in leases and queues requests for the card. It waits for an active request or image job to finish, unloads the managed engine, and checks that the driver reports freed memory before admitting the next workload. This covers different applications rather than only models within one chat server. Processes outside its lease system are reported, leaving the owner responsible for investigating them.

A community request becomes a development-branch change

One participant in the original Reddit discussion wanted batch work to run while away or when electricity was cheaper. The author first explained the existing background queue, then acknowledged that it had no time-of-day awareness and added that capability. PR 290 merged into next at 15:13:29Z on November 2. A window such as 23:00–07:00 can span midnight. Outside-window requests wait without obstructing other queued work; closing the window drains at a task boundary. Pinned leases and hold priority cannot use it because they must not be automatically drained. This is a traceable request and implementation, not evidence of how many users need the feature.

Inspect the queue and the provenance of the display

Harbor groups the current holder, memory history, queue position and engine state in a web interface. Its phone layout moves tabs to a bottom bar. A waiting explanation helps distinguish an unfinished competing job from a window that has not opened. The repository explicitly labels its first two interface images as built-in demo data; only the third is described as an iPhone viewing a live node. Demonstration counters therefore cannot substantiate resource savings. Telemetry distinguishes driver measurements from engine-reported figures, and an unmeasured start is not assigned a fabricated estimate. The display supports diagnosis while leaving workload priorities with its operator.

Check the branch and the supported machine

The Apache 2.0 project primarily supports Linux with NVIDIA. Windows and selected AMD paths remain experimental, while Apple and Intel are outside the stated support matrix. The time-window change is on next; normal updates do not automatically install prereleases. A tester should preserve configuration and a route back to the released version. Scheduling does not make an oversized model fit into insufficient VRAM. Start with two short jobs and inspect waiting, completion, release and restart, then try a midnight-spanning window and daemon restart. If integration effort or repeated reloads outweigh the avoided manual switching, a simpler script may remain the better fit.
