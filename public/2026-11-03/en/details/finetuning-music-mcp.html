Turn a soundtrack brief into a generation task

Finding a background track for a podcast often starts in one conversation and continues in a separate generation form. Finetuning’s MCP connection lets an assistant use an existing account to create music, wait for completion and retrieve the result. The brief still needs useful musical direction, and the creator still has to hear whether the track competes with speech. The November 2 change concerns integration and Plus API eligibility rather than a new audio model. An assistant carrying out the request does not establish that it can choose the most suitable score. Keep the intended scene and the listening decision visible instead of treating a completed request as a finished soundtrack.

Authorization does not remove spending boundaries

Authorization uses a browser consent page with OAuth and PKCE, without copying an API key. Each agent receives a named account entry that can be revoked; the next request is then refused. Active Plus, Pro and qualifying lifetime plans can connect. Creation tools preview cost and accept a maximum, refusing an over-limit request before creating anything. Songs and instrumentals use a generation each, while sound effects draw from a separate daily allowance. These controls help express a bounded request such as trying a few directions. They do not establish that an entire account budget, or the cumulative cost of repeated attempts, has automatically been understood by the creator.

Keep generation identity through waiting and cleanup

The tool reference separates creation from retrieval: an asynchronous request returns an identifier, followed by waiting or status checks. After a timeout, checking the same identifier avoids accidentally creating a second track just to obtain a response. Library cleanup also needs precise objects. The documentation states that deletion is permanent and advises confirmation first. Test a disposable playlist to distinguish moving a track, removing it from a list and deleting the generation itself. A successful tool response only confirms an interface action. Verify that the track, ordering and downloaded result correspond to the version the person actually selected, particularly after several similar attempts have accumulated.

[S41]

Provenance and permitted use answer different questions

Uploads, reimagining and vocal removal are excluded from MCP because the person must confirm rights to supplied material. An agent can retrieve a generation certificate, but provenance does not establish uniqueness. The published license distinguishes personal and commercial access and restricts exclusive claims and stock-library resale even for paid plans. Before delivery, keep the selected version, its source and the intended project together. A client requiring exclusivity or a particular distributor’s acceptance may need a different arrangement. Those requirements should be checked against the actual agreement rather than inferred from a commercial-use label. The integration can reduce administrative steps while leaving the substantive listening and usage decisions with the creator.
