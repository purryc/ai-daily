Point to the branch under discussion

Discussing a map in a separate chat often requires copying its headings and explaining which branches may change. Desktop version 27.01.05086 adds topic references and attachments to the agent conversation, giving the request a more explicit context. The same release adds link previews and embeds. This can keep supporting material closer to the structure being developed. It is especially relevant after a first draft already exists and several options need comparison. A person must still check the meaning of each relationship: evidence, assumption and action are different things. A neat hierarchy can make an unsupported argument look settled, so layout should not substitute for inspecting the underlying material.

Keep the platform and release date together

The dated evidence is the October 28 desktop changelog, so this belongs in a seven-day lookback. November 2 promotion of Xmind 2027 does not make it a new release that day. The official site had already described in-map chat for the web in June. The desktop entry additionally records setup guides for MCP and CLI, along with synchronization and saving fixes. That platform distinction affects a mixed team: one person may use the browser while another works in a desktop file. Check the installed version and available controls in both places. A shared product name does not establish that every client received the same change at the same time.

Cloud workspace access differs from local-file access

The integration guide describes an authorized MCP connection for external assistants and limits it to maps in My Works. The AI page separately describes skills and a CLI for native local files. These are different paths, with different locations and access assumptions; local-file editing should not be described as the same operation as a synchronized cloud change. Before connecting an assistant, identify the editable copy and the material it contains. After a small revision, inspect untouched branches, attachments and links. Successful authentication only establishes access. It does not tell the agent which structures represent an approved decision, or whether an apparently redundant branch is still needed by another collaborator.

Spend generation effort where revision is useful

The pricing page distinguishes fifty signup AI credits from Premium’s five hundred monthly credits. Free access includes ten online maps and a shorter version history, while paid plans change collaboration and recovery allowances. The displayed monthly equivalents were not verified as monthly billing quotes, and no credit cost for a complete research-to-map task was measured. Test a real branch against the current manual method, counting correction time as well as generation. If most of the hierarchy must be rebuilt, a maintained template may remain simpler. If a few targeted changes are enough, keeping context inside the map can reduce the repetitive work of explaining and reconstructing it.
