Issue keys instead of sharing credentials

Sharing a provider credential across a team makes individual offboarding awkward: revoking one person can interrupt an unrelated service. Langfuse separates provider credentials from user and service-account gateway keys. Applications change the endpoint and key while retaining the native API format. Requests still reach the model provider; the gateway adds attribution and recording rather than local inference. Before adoption, a team should list which applications will use that route and which will continue calling providers directly. Otherwise an orderly dashboard can create a misleading impression of organization-wide coverage when only part of the traffic is visible.

Recording mode changes the questions available

Full recording retains inputs and outputs; usage-only mode omits that content. The analytics page also respects role boundaries, showing ordinary gateway users their own traffic and administrators broader breakdowns. Its documentation explicitly limits charts to gateway-recorded generations. Ordinary SDK traces in the same project do not become gateway usage. That boundary affects interpretation: a falling chart could reflect traffic leaving the gateway rather than improved efficiency. Teams wanting departmental attribution should decide key metadata in advance. A model name alone rarely provides enough context to assign a shared service’s spending to the work that actually caused it.

Codex has specific capture limitations

The Codex integration groups a user turn into a trace with model rounds beneath it. Its documentation warns that oversized inputs are dropped beyond the five MiB capture limit. Top-level trace input and output come from the final model round, so they are not a literal copy of the whole conversation. It also warns that estimated costs for failed and cancelled calls can be inflated pending a fix. Having a record for every request therefore does not mean every field supports reliable content auditing or reconciliation. Operators investigating anomalies need to understand the capture rules before comparing the dashboard with provider billing or detailed execution logs.

Test revocation and reconciliation

A modest trial can use one interactive user and one continuous-integration service. Check revocation, model allowances and recording permissions, then reconcile usage against the provider to identify missing or duplicate records. Deliberately include a failure and cancellation so inaccurate estimates do not become automatic judgments about an employee’s spending. Beta routes and headers may change, and a complete tariff was not verified here. The gateway does not replace evaluation of answer quality. Its more concrete adoption case is reducing shared credentials and making the origin of model calls inspectable without confusing recorded activity with complete financial accounting.
