google-gemini-agentEvent date 2026-10-08vgemini-at-work-2026confirmed product

Google Gemini agent turns one prompt into a persistent work coworker

What it is

Gemini agent is Google Cloud's newly announced universal enterprise agent. A user gives it an objective in one prompt; it selects models, skills, and tools, connects to business systems, runs persistently, and returns finished work into the surfaces where the team already works.

What changed

The dated announcement combines persistent execution, dynamic sub-agents, coworker identity, a skills registry, four memory types, MCP connectivity, an Agent Sandbox, an Agent Gateway, agent-attributed audit, Smart Routing, and real-time spend caps.

When to use it

A user can ask it to research a market, build a Sheets model and a Slides deck, write and run code, respond to events, or act as a project manager or finance analyst. A team can create a coworker agent with its own account, role, storage, and permissions.

Limits & availability

This is an official announcement with company-reported customer examples, not proof of a complete public product matrix. Price, regions, exact plans, latency, error rates, retention, and the permission details of every connector are source not stated.

google-workspace-inline-agentEvent date 2026-10-08vinline-coworker-2026developer surface

Workspace inline agents put the coworker's identity inside email, docs, and comments

What it is

Workspace inline agent is the concrete interaction surface for Gemini inside Google's work suite. The same memory, skills, and controls are described as travelling into Gmail, Drive, Docs, Slides, Sheets, Chat, and Calendar.

What changed

Google describes three modes: personal assistance, proactive delegation, and a coworker agent. The system can recognise a delegatable task in a manager's email or create a team agent with its own Workspace identity.

When to use it

A user can let it identify the usual meeting group and coordinate calendars, carry a project between email and documents, create reports and decks, receive an @mention in Chat, or suggest an edit in a Doc comment under its own version-history identity.

Limits & availability

The announcement does not show the live UI, default permissions, audit presentation, undo flow, or the full scope of each Workspace plan. Exact rollout, price, and region are source not stated.

surface-laptop-ultra-rtx-sparkEvent date 2026-10-07vsurface-laptop-ultra-2026confirmed product

Surface Laptop Ultra makes local model execution a first-class PC workflow

What it is

Surface Laptop Ultra is Microsoft's high-end Windows AI PC built around NVIDIA RTX Spark, accompanied by a Surface RTX Spark Dev Box preloaded with developer tools.

What changed

Microsoft lists up to 6,144 Blackwell GPU cores, a 20-core Grace CPU, and 128 GB of unified memory, and positions the devices for local inference, evaluation, GitHub Copilot tasks, and agent workflows. Pre-orders are open.

When to use it

Developers can run inference, evaluation, and coding agents locally while reserving the cloud for work that needs it. The Dev Box ships with Visual Studio Code, Git, GitHub CLI, GitHub Copilot, WSL, Python, Node, and related environments.

Limits & availability

Surface Laptop Ultra starts at $2,599 and availability begins October 16. Battery life, sustained local throughput, thermal behaviour, independent testing, and the complete regional configuration matrix are source not stated.

microsoft-execution-containersEvent date 2026-10-07vga-2026-10-07developer surface

Microsoft Execution Containers make an agent's file and network boundary a runtime policy

What it is

MXC is Microsoft's policy-driven containment layer for agent execution, not a standalone chat app.

What changed

It is now announced as generally available. Developers declare file and network requirements through a unified JSON schema and multi-language SDK; MXC selects a process, session, WSL, VM, or other containment backend at runtime.

When to use it

When an agent needs a project directory, network access, or code execution, the platform can establish a boundary from the declaration and organisational policy. Enterprises can connect the signal to Intune, Agent 365, Entra, Defender, and Purview.

Limits & availability

The official release describes containment and governance, not independent security assurance. Default policies, backend differences, misconfiguration recovery, and the GA scope across every platform are source not stated; the early GitHub repository still warns against treating preview profiles as final security boundaries.

github-copilot-cli-local-modelsEvent date 2026-10-07v1.0.94-0developer surface

GitHub Copilot CLI adds /model discovery for Ollama, with an explicit local-is-not-offline boundary

What it is

This is GitHub Copilot CLI's local-model provider experience: the CLI can discover supported models from a running Ollama instance.

What changed

From CLI 1.0.94-0, /model lists local, configured, and GitHub cloud models. Users can review the provider and endpoint, then use the model only for the current session or add it without switching.

When to use it

Developers can choose a model without leaving the terminal, and connection failures appear with an explanation. The model must already be installed and support tool calling and streaming. The flow does not install Ollama, download a model, or automatically enable offline mode.

Limits & availability

GitHub explicitly says that choosing a local model does not mean offline mode and does not disable telemetry. Intelligent routing is still a stay-tuned announcement, while enterprise policy, IDE parity, and complex-agent quality need testing.

devally-agentEvent date 2026-10-08vagent-journeys-beta-2026startup signal

DevAlly Agent records real user journeys before a human reviews accessibility findings

What it is

DevAlly Agent is a startup accessibility-compliance workflow: describe a user journey in natural language, let an agent walk it in a real browser, and record the path.

What changed

The launch shifts attention from page scans to complete task flows. Each finding includes a WCAG criterion, element, screenshot, and suggested fix, and a Workflow can be rerun after every release.

When to use it

A team can ask it to test signup, checkout, booking, forms, or password reset, review that it took the intended path, monitor regressions, and send suggested fixes into an editor through DevAlly MCP.

Limits & availability

It remains a beta, and the maker explicitly says it does not replace a human audit. Hover-only menus, drag and drop, and iframes are not supported; real screen-reader and complex-authentication flows still need people.
