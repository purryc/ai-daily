google-gemini-agent进展日期 2026-10-08vgemini-at-work-2026confirmed product

Google Gemini agent：把企业工作交给一个持续运行的工作同事

产品是什么

Gemini agent 是 Google Cloud 在 Gemini at Work 2026 宣布的统一企业 Agent：它从一个 prompt 接收目标，选择模型、skills 和 tools，连接企业系统，持续执行并把结果放回用户已有的工作面。

这次变化

新公开的组合包括 persistent execution、dynamic sub-agents、coworker identity、skills registry、四类 memory、MCP connectors、Agent Sandbox、Agent Gateway、audit trail、Smart Routing 和实时 spend caps。

什么时候用

用户可以要求它研究市场、生成 Sheets 模型与 Slides、写并运行代码、响应事件、按角色担任项目经理或金融分析师；团队也可以为它创建独立的公司账号与职责。

限制与可用范围

这是官方发布与客户案例，不等同于公开可用的完整产品矩阵。价格、地区、具体套餐、延迟、错误率、数据保留和所有 connector 的权限细节 source not stated。

google-workspace-inline-agent进展日期 2026-10-08vinline-coworker-2026developer surface

Workspace inline agent：让 Agent 在邮件、文档和评论里留下身份

产品是什么

Workspace inline agent 是 Gemini agent 在 Google 工作套件里的具体交互面：同一套记忆、技能和控制进入 Gmail、Drive、Docs、Slides、Sheets、Chat 与 Calendar。

这次变化

Google 公开了 personal assistance、proactive delegation 和 coworker agent 三种形态；系统可以从经理邮件识别可委派任务，也可以创建拥有独立 Workspace 身份的团队 Agent。

什么时候用

用户可以让它找团队成员并协调会议、跨邮件和文档整理项目、生成报告和 deck、在 Chat 中被 @mention，或在 Docs 评论里提出修改并写入自己的版本历史。

限制与可用范围

发布稿没有展示真实界面、默认权限、可见日志、回滚交互或不同 Workspace 套餐的完整范围；具体 rollout、价格和地区 source not stated。

surface-laptop-ultra-rtx-spark进展日期 2026-10-07vsurface-laptop-ultra-2026confirmed product

Surface Laptop Ultra：把本地模型和 Agent 执行搬回桌面硬件

产品是什么

Surface Laptop Ultra 是 Microsoft 与 NVIDIA RTX Spark 联合设计的高端 Windows AI PC，旁边还有预装开发工具的 Surface RTX Spark Dev Box。

这次变化

Microsoft 披露最高 6,144 个 Blackwell GPU cores、20-core Grace CPU、128GB unified memory，称设备可本地运行 demanding models、GitHub Copilot tasks 和 agent workflows，并开放预购。

什么时候用

开发者可以在本地跑推理、评估和编码 Agent，让 cloud 只承接需要它的任务；Dev Box 面向桌面开发，预装 VS Code、Git、GitHub CLI、Copilot、WSL、Python 与 Node。

限制与可用范围

价格从 $2,599 起，供应从 10 月 16 日开始；电池、实际端侧吞吐、长期散热、独立测评和完整地区矩阵 source not stated。

microsoft-execution-containers进展日期 2026-10-07vga-2026-10-07developer surface

Microsoft Execution Containers：把 Agent 的文件和网络边界变成运行时政策

产品是什么

MXC 是 Microsoft 为 Agent 运行提供的 policy-driven containment layer，不是一个单独的聊天应用。

这次变化

它现在宣布 GA；开发者用统一 JSON schema 和 multi-language SDK 声明文件、网络等需求，MXC 在运行时选择 process、session、WSLc、VM 等 containment backend。

什么时候用

Agent 想读项目目录、调用网络或运行代码时，系统先根据声明和组织政策建立边界；企业可以把它接到 Intune、Agent 365、Entra、Defender 和 Purview。

限制与可用范围

官方强调边界与治理，但独立安全验证、默认策略、不同 backend 的差异、错误配置恢复和所有平台的 GA 范围 source not stated；GitHub 早期仓库仍提示不要把 early profiles 当最终安全边界。

github-copilot-cli-local-models进展日期 2026-10-07v1.0.94-0developer surface

GitHub Copilot CLI：用 /model 发现 Ollama，本地不等于离线

产品是什么

这是 GitHub Copilot CLI 的本地模型 provider 体验：CLI 可以从正在运行的 Ollama 实例中发现支持的模型。

这次变化

从 1.0.94-0 起，/model 同时展示本地、已配置和 GitHub 云端模型；用户可先查看 provider 与 endpoint，再选择只对当前 session 使用或添加而不切换。

什么时候用

开发者无需离开终端就能选择合适模型；连接失败会在 picker 中解释。模型必须已经安装，支持 tool calling 与 streaming；该流程不会安装 Ollama、下载模型或自动打开 offline mode。

限制与可用范围

GitHub 明确写明 local model 不等于 offline，也不关闭 telemetry；intelligent routing 仍是 announced / stay tuned，企业权限、VS Code 对应体验和复杂 agent 的质量尚待验证。

devally-agent进展日期 2026-10-08vagent-journeys-beta-2026startup signal

DevAlly Agent：先记录真实用户旅程，再让人复核无障碍结果

产品是什么

DevAlly Agent 是一个 startup accessibility-compliance workflow：用自然语言描述用户旅程，Agent 在真实浏览器中走一遍并记录。

这次变化

发布重点从扫描页面变成扫描完整任务流程；每个 finding 带 WCAG criterion、元素、截图和建议修复，Workflow 可在每次发布后重跑。

什么时候用

团队可以让 Agent 测试注册、结账、预约、表单和密码重置，人工先确认它确实走了正确路径，再持续监测回归，并通过 DevAlly MCP 推送到编辑器。

限制与可用范围

它仍是 beta；官方和 maker 明确说不替代人工审计。hover-only menus、drag and drop、iframes 当前不支持，真实屏幕阅读器和复杂认证流程仍需人测。
