User and actual change

The maker wanted to give a coding agent tasks while away from the keyboard and connected ordinary radios to a Mac. The October 19 Product Hunt calendar establishes a launch observation, but an earlier maker comment means it should not be treated as the project’s birth date. The hardware combination is a software bridge using two existing VOX-capable radios and an audio cable, not a newly invented AI transceiver. A suitable task is checking a build or starting work that can be inspected afterward. Tasks requiring continual diff review, complex permission decisions or visual verification still bring the operator back to a screen. [walkai-talkai-1][walkai-talkai-2]

Full workflow and controls

A handheld push-to-talk transmission reaches the station radio, which feeds audio to the Mac for local Whisper transcription. Target Window mode submits the text to the selected agent window through macOS Accessibility. The agent must return a short response to the local reply API, after which synthesized speech goes back through the station’s VOX transmitter. Listening can be paused, the target selected and command history inspected. A delivery beep acknowledges submission, not successful task completion. API mode can instead contact a model endpoint, so local audio processing does not mean every inference stays offline. Adoption requires Apple Silicon, macOS 13 or later, wiring and permissions. We only read documentation and did not use the user’s Mac. [walkai-talkai-3]

Silence has several causes

Official troubleshooting separates the wrong input device, noise transcription, a misplaced target window, missing reply protocol and VOX truncating speech. It also acknowledges that other people on the frequency can trigger commands. These are vendor-documented failure conditions, not problems reproduced here. PM inference: when no answer arrives, the operator needs to distinguish an undelivered request, an agent still working and a failed spoken reply. Repeating the instruction without that distinction could execute it twice. Recorded audio helps explain misrecognition but does not establish that the code is correct. A half-duplex interface needs concise, distinguishable acknowledgments and an explicit human decision for irreversible work. [walkai-talkai-4]

Alternative, cost and validation

Compared with ordinary dictation at a desk, the additional value is the return channel while the operator is away. If the user remains beside the display, wiring and radio latency may not be worth the added complexity. The software has a one-Mac lifetime license, while radio hardware and any chosen cloud-model charges are separate; this review bought nothing and created no credentials. A falsifiable test would compare keyboard, ordinary voice and radio for ten identical read-only status queries. Measure recognition, truncated words, duplicate requests, reply latency and trips back to the screen; then move the target window and disconnect the audio device. Fewer interruptions with preserved confirmation would establish a useful niche.
