Use the screenshot as input

The formal Hy4 guide adds image understanding and permits text and image parts in one message. An application can submit a chart, interface capture or photographed text together with the user’s question. TokenHub accepts a reachable image URL or an encoded image inside the request. The latter avoids first placing an internal screenshot at a public address, but the image still travels to the cloud service. For someone working from a table capture, avoiding manual transcription is useful. The remaining task is checking that the answer associates numbers with the correct units and columns. A plausible description is not a verified extraction.

Preserve state between tool calls

Tencent’s interleaved-thinking documentation assigns clear responsibilities: the model returns a tool request and reasoning content, the application runs the tool, and the next request returns both the result and same-turn reasoning state. The model may then request another action before answering. Integrating this behavior requires more than changing a model name. Middleware that preserves only visible final text can discard state needed for continuation. It also needs to distinguish a requested action from a successful execution. That distinction matters for file changes or external systems, where a generated call is not evidence that the work happened. This is a documented interface contract, not a measured long-task success rate.

Image detail and service region have boundaries

The model-specific guide recommends higher detail for small text, tables and screenshots, while explaining that oversized images are eventually reduced. More uploaded pixels therefore do not provide unlimited visible detail. It lists a maximum of 600 images per request, whereas the generic image page also contains a no-hard-count-limit statement. That documentation inconsistency deserves confirmation before a bulk workflow is built around either value. Separately, TokenHub distinguishes Guangzhou and Singapore endpoints and requires the service region to match. Protocol compatibility can reduce integration work, but it does not resolve regional configuration, input quality or conflicting batch-limit guidance. Those are operational choices the application still has to handle.

Hosted pricing is listed; weights remain forthcoming

The China price page lists RMB 6 per million input tokens, RMB 18 for output and RMB 0.3 for cache hits. It applies a 50 percent promotion from the notice through December 31 at 23:59:59 Beijing time. That condition matters for a trial budget but should not be generalized to other providers or later usage. Release reporting still describes model weights and the system card as forthcoming. The verifiable present offering is hosted access with documented interfaces. Comparing a migration should include image input volume, tool round trips and review time, alongside the quoted rates. A cheaper response is not necessarily a cheaper completed task.
