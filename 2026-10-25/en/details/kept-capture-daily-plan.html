Inspect the interpretation before saving

Remembering something can first require deciding whether to open a calendar, task list or notes app. Kept supplies a shared capture entry: type or dictate mixed material, then inspect the proposed title, date, time and destination. Its 1.9.9 notes describe this preview using an appointment sentence with a day and time. Ranges retain both endpoints, switching to a note preserves the wording, and extra lines become description text. This reduces copying and choosing between entry points. It does not settle every ambiguity in language. Relative dates, an unstated morning or evening, and several intentions in one line still deserve inspection before saving. Visible fields make those mistakes easier to catch than a simple confirmation that something was arranged.

Suggestions should not silently reorder the day

Kept combines the calendar, goals and unfinished work to suggest three priorities, with reasons that the person can inspect. The plan remains editable, and suggested time placement waits for approval. This release explicitly keeps newly added tasks from reshuffling the existing Top 3. Saving a replanned day retains the proposal just reviewed; the person can ask again if circumstances have changed or cancel while waiting. These details address a familiar irritation: recommendations that change on every refresh make it difficult to tell whether a commitment actually moved. Event editing has similarly bounded behavior. Moving a start time preserves duration, while editing a title leaves its times alone. A proposed priority and an appointment already promised to someone remain different objects.

Keep the plan beside its details

Version 1.9.9 also reorganizes unfolded, two-pane views. A calendar month can sit beside a selected day, task and goal lists beside their details, and the Today timeline beside the Top 3. This uses available screen space; it introduces no new sensor and provides no evidence that the planner became more accurate. It can remove repeated back navigation and the need to remember one screen while comparing another. Platform requirements differ by distribution. The iPhone App Store listing requires iOS 18 and lists compatibility on Apple Silicon Macs from macOS 15. The separate native Mac version on the website requires macOS 26 and lists both Intel and Apple Silicon. Those are distinct installation paths, not interchangeable requirements.

Find and reverse what filing changed

The release makes filing edits visible in Changes by Kept, with a way to review and undo them. Deleting a parent note also asks what to do, and children can move to the top level. That is useful because a familiar location is part of remembering a note; a tidier directory can still make something harder to find. The privacy documentation distinguishes on-device processing, account sync and optional cloud AI, which may send relevant context to external model providers. Apple Intelligence therefore does not make the entire service local. Overnight filing has a separate preference, and stopping future processing does not recall an existing edit. Kept is free to start, but full paid entitlements were not established. Its practical benefit depends on fewer steps across capture, confirmation and retrieval together.
