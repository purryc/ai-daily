A box cannot describe the space between table legs

A bounding box around a table is useful for its overall size, but it also encloses the empty space between the legs. A placement model that sees only that box can mistake a chair beneath the table for an intersection with solid furniture. GALA gives each object its actual point cloud alongside category, size, pose, room boundaries and a placement instruction. It targets concrete relations such as support, containment, underneath and proximity: a book inside a cabinet cavity or a cushion resting on a curved surface. Its output is a position and three rotation angles for the target object. These values update the scene object rather than producing a plausible-looking interior photograph.

Learning geometry before predicting placement

The first training stage connects point-cloud features to the language model through a learned projector, using questions about boundaries, centers, dimensions, orientations and distances. The second stage keeps the point encoder fixed while tuning the projector and language model to predict an instruction-conditioned six-dimensional pose. Training scenes combine public indoor collections, procedural generation and three hundred artist-crafted scenes. Physical and geometric checks remove unsuitable examples before a vision-language model evaluates them. This preserves the shapes of supplied assets instead of asking the language model to infer dimensions from names alone. Clean, filtered scenes nevertheless differ from noisy scans of real rooms; the reported results do not establish equivalent behavior on those inputs.

A complete room needs a checking loop

The authors wrap the placement model in planning, instruction-generation and verification agents. A room request becomes an object list and evolving scene state. Retrieved assets are passed to GALA one at a time with a relation instruction. After insertion, a verifier checks collision, floating, room boundaries and the intended relationship; failures return to the instruction generator for another attempt. This associates an error with a specific object and step rather than requiring a new flattened image. Sequential prediction also means an early mistake changes the space available to later objects. The checking loop does not eliminate accumulated errors. Instructions use a predefined relation vocabulary; unrestricted language and continuous interactive editing remain beyond the demonstrated system.

Separating insertion accuracy from scene ratings

Single-object insertion on the held-out set reports 65.62% valid containment, 78.59% instruction validity, 4.63% floating and 96.03% valid support. These metrics answer different questions, and baselines without instruction input cannot be compared across every column. Removing point clouds reduces containment performance but slightly increases instruction validity, so geometric input does not improve every measure. Thirty volunteers also rated displayed results; that is not a study of professional production time. For scene-tool developers, the useful mechanism is retaining editable objects and testing their geometric relationships. Complete code and data availability, as well as dependable performance on unfamiliar containers, remain unresolved. The publication is a research result, with no independent reproduction reported here.
