A missing card can hide a waiting task

When several agents are running, remembering a task name is not enough: the person also needs its project and whether it is waiting for them. Bloblings places sessions in an edge drawer and uses pets to depict editing, command execution and waiting. Clicking returns to the original thread. The characters help with a quick glance only if they map to the correct sessions. Version 1.0.27 addresses that basic mapping by restoring Codex New chat sessions outside a project, with the relevant display preference on by default. The update repairs visibility rather than model intelligence. An absent card should never be treated as proof that no work is running in the background.

Keeping a child run with the task that started it

The same release places a codex exec run launched by a Claude thread beneath that thread as a subtask instead of presenting it as an independent conversation. Clicking still opens the run in Codex, and the maker asks users to rerun the Codex setup prompt to obtain the behavior. This hierarchy matters because delegated work is not a second unrelated request. Following the parent-child relationship should reduce reconstructing context or issuing duplicate instructions. It does not remove awkward cases such as a parent stopping while a child still changes files. A character animation cannot settle those states. The release describes intended behavior without providing a complete failure and reconnection test matrix.

Passing a note does not transfer approval authority

Bloblings supports short notes between threads instead of giving them unrestricted access to one another’s full conversations. Version 1.0.27 also repairs waking an idle thread when a note arrives. The current site describes automatic delivery, delivery on a click, or disabling the exchange. A small note about a renamed interface can make a request easier to inspect than copying an entire conversation, but a summary can still omit context. The drawer also does not currently answer approval prompts: the person returns to the original thread. Delivery, waking, authorization and completion remain separate events. An envelope animation cannot establish that the receiving agent understood or completed the requested change.

Check session coverage before choosing a theme

The app is free and requires macOS 15 or later. Its maker describes local hooks and files as the source of status, and distinguishes ordinary Claude conversations from Code sessions that report actions. A card therefore depends on correct integration, not merely on having a chat window open. The claim that the panel itself makes no network requests does not mean that Claude or Codex model inference is also offline. The homepage currently names 1.0.28, while the readable update page identifies 1.0.27 on October 20; this item uses that verified seven-day lookback rather than inventing a newer date. Check expected sessions, click destinations and end states before deciding whether a persistent pet drawer demands less attention than ordinary notifications.
