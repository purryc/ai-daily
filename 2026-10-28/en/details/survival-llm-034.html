Download first, then retrieve without a connection

Survival LLM is intended for finding information when a network connection is unavailable. Before that happens, the user downloads the application, a model matched to available memory, and a reference pack. A question goes to a local model through Ollama; library tools search a SQLite full-text index and read passages. Clicking a cited article opens its text beside the answer with the relevant passage highlighted. Personal PDFs, Word files, ebooks and manuals can join the collection. This reduces the repeated keyword guessing involved in searching separate offline documents. Personal imports do not yet read scanned pages or photographs, so preparing a useful collection still requires checking that the files contain extractable text.

Search activity can still end in a blank response

Version 0.3.4 addresses a concrete failure: a logged Granite run spent six rounds searching, opened no articles, and emitted another tool request that the application filtered into an empty answer. The report analyzed existing logs rather than running a new experiment, and the maintainer confirmed the behavior. The fix provides the best retrieved articles for one additional attempt without tools. Beside Send, a reasoning budget now allows no reasoning, several token limits or an unlimited setting. Reaching a limit ends further thinking and asks for an answer. These controls address an unexplained wait and missing output; neither retrying nor removing a limit guarantees that the resulting facts are correct.

Provenance, memory and quitting need separate fixes

The update distinguishes an answer from model memory, an answer based on opened articles, and one based only on search results. An explicit request to look something up now triggers retrieval even after a memory-based response. Adjacent releases address questions incorrectly saved as personal facts, search commands presented as sources, and duplicate articles filling the result list. Quitting the Mac application had also left its bundled Ollama process and loaded model running; the related fix releases those resources. These failures affect different parts of ordinary use: personalization, evidence, retrieval coverage and available memory. Turning off memory saving does not erase retained notes, which remain available for inspection and editing.

Treat the reference path as something to inspect

The Mac and Windows application is free, with MIT-licensed code and separate licenses for library material. Offline use still requires advance storage, power and adequate memory. The author's 22-question evaluation used AI judges and an older library containing some material absent from public downloads; some evaluated model files also differ from installed ones. A zero-harmful-answer entry therefore cannot establish a safety guarantee for the current package. A community analysis of the stored logs further questioned whether higher answer scores meant more relevant articles were actually opened. The useful interface question is what source the reader can inspect and what remains unverified. No emergency or medical task was independently executed for this report.
