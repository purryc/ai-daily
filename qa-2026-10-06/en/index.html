HyperFrames Studio shares the timeline; today's patch improves preview memory

What it is

HeyGen's desktop editor lets a coding agent and a person work on one video project

What changed

Today's v0.8.137 reduces preview-loading memory for large inline assets and flags excessive audio peaks; desktop setup guides arrived October 5

When to use it

Describe a cut, then point, draw, comment on a frame or adjust the timeline before sending grouped edits to the agent

Limits & availability

Official setup covers macOS and Linux x86_64, with HeyGen sign-in and your own agent; a Windows download wasn't verified
