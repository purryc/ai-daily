Expose the hidden wait

Agent Pets starts from a specific coordination failure: a developer assumes several agents are still working, while one terminal has stopped at a permission prompt. The October 21 launch represents Claude Code, OpenCode and omp sessions as pets at the bottom of browser pages, with capsules indicating progress or a need for input. The proposed benefit is less repeated terminal checking, not a stronger model. Product Hunt establishes a public launch presentation rather than the exact first availability of every package. The current website contains a broader compatibility list, which should not automatically be projected back onto the original launch.

The browser becomes an action surface

The documented setup connects a local helper and agent hooks to a Chromium extension. A person opens the waiting pet, reads the command or file request and then allows, denies or replies. This makes the browser an action surface rather than a purely decorative notification channel. Support is not identical across agents: omp permission handling remains in the terminal. A browser may also contain unrelated work, making session identity especially important. Acceptance should check whether someone can reliably identify the requesting session, directory and action before responding. Recognizing a familiar character is not the same as understanding the command it represents.

Hiding a pet is not cancellation

One recovery distinction is easy to miss: despawning a pet does not terminate its underlying agent. Clearing the screen and cancelling work are separate intentions that the interface must keep understandable. The vendor describes the helper’s work-data handling as local, while licensing and updates still involve network requests. That description cannot make the underlying coding agent’s model calls local. The privacy page observed here is dated October 22 without an exact update time, so it is current explanatory material rather than a tested pre-cutoff guarantee. No extension or helper was installed, and no permission request was approved during this research.

Account for attention and mistakes

The website displays an early one-time price of $6, a regular $25 price and up to three browser activations per license; checkout currency and real compatibility were not tested. Desktop notifications, terminal sounds and a regularly checked task queue are alternatives, potentially with less setup but fewer in-page response controls. A falsifiable trial should measure minutes spent waiting for a person alongside duplicate notifications, mistaken approvals, session confusion and successful cancellation. Faster responses are not beneficial if they encourage casual approval of complex commands. The design earns its place when users reach the correct request sooner while preserving the same quality of scrutiny and recovery. The record should distinguish receiving a notification, understanding its request and responding correctly, rather than using the number of clicks as a completion metric.
