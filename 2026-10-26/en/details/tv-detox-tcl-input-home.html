Keep the original launcher and redirect Home

TV Detox starts with a coding agent on a computer sharing the television’s network. The owner identifies the model and apps to keep; Claude Code or Codex helps inspect packages, explain proposed changes and request confirmation. Apps are disabled rather than deleted, with an undo route retained. AI belongs to this setup process. Version 1.5.4 adds a Home-button Accessibility option that leaves Google TV’s launcher enabled while opening the replacement over it. Holding Back temporarily returns to Google’s home; repeated launch failures stop redirection. The project reports testing this route on a Chromecast HD running Android 14 and in a Google TV emulator.

A detected console still needs an input player

A TCL Smart TV Pro owner removed com.tcl.tv because they did not watch broadcast television, following the earlier notes. The television still detected a Steam Deck on HDMI 3, but neither the remote’s input picker nor the launcher tile opened its picture. The contributor traced a distinction between the signal service and the activity that displays it: the removed Live TV package contained the only suitable player. Restoring it brought back HDMI and the input picker on that same Google TV 14 set. Version 1.5.5 marks the package as never-disable and corrects the advice. This is a documented single-device failure and recovery, not a series-wide compatibility result.

Name the input and reach the television’s own panels

The same release sequence improves ordinary remote use. Hold OK on an HDMI tile to choose a console name, type a custom label or remove it from Home. Hidden inputs can be restored through the Add app tile’s menu. Labels affect this launcher only. Version 1.5.6 also corrects Sound, Picture and Brightness shortcuts on TCL Q651G televisions. Their vendor panels live inside Android’s settings package rather than the package name previously expected, so the old path fell back to generic pages. The new fallback resolves the actual panel. A contributor reports testing Picture on a 50-inch Q651G and documents setup observations from two Q651G sets.

Device reports keep unresolved limits visible

The contributor does not turn every observation into a solved defect. Two Q651G sets forgot Wi-Fi during installation, with the cause still unclear, and some remote app buttons depend on vendor components that cleanup may disable. The Philips Home-routing fix was tested only with simulated behavior on Android 9 and 11. Installation guidance retains system essentials, checks behavior after restarting and closes debugging afterward. These controls belong to setup, not an intelligent launcher runtime. Reversing package switches is supported, but the documentation also records boot failures that required factory resets. The improvement is more specific device knowledge; owners still need to verify their own firmware, inputs and remote buttons.
