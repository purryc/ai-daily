Monish gives people running scripts or coding agents an iPhone view of progress, results and pending questions.

Instant finds Mac files from remembered content

Instant is for Mac users who remember what a file contained but cannot recall its name or folder.

Choose folders for a local index, press Option-Space and describe the content; results show matching files and passages. A source preview highlights relevant passages so the reader can inspect surrounding conditions immediately.

The maker describes late-interaction embeddings, with support for text, photographs and scans without a text layer. Files stay in chosen folders, with subsequent indexing limited to changed material.

It is free and accountless on macOS 15+, with an approximately 1 GB model download and potentially lengthy initial photo indexing. Update checks and optional anonymous telemetry are separate network activities.

Product perspective

The advertised 95% hit rate has no disclosed test protocol and is not a guarantee for a personal file collection.

CARL asks what the reward should mean before it writes the training pipeline

CARL lets domain experts specify a reinforcement-learning problem through conversation before writing a training script.

It confirms objectives, state, actions, rewards and training choices before generating, testing and running code. People participate in the first seven of ten stages, accepting, editing or rejecting proposed answers.

BrickWright lets creators describe a brick model in text or images and have a coding agent produce an editable structure.

BrickLayer supplies part search, connector alignment, collision and floating checks, followed by rendering and LDraw output. The agent creates an assembly program, using connectors instead of calculating every absolute part position.

PointerBench asks whether an agent can hit the divider, not just find the cell

PointerBench studies the small targeting errors that frustrate computer-use agents: dividers, carets and tightly bounded selections.

Given a screenshot and instruction, the model returns a pixel point or box; 1,500 tasks separate targeting from planning. JSON points or boxes follow an explicit output contract; malformed responses fail.

The new paper compares spreadsheets, text and generated professional interfaces at several target sizes. Screenshots are fixed at 1024 by 768; changing display scale changes target geometry, and professional interfaces are generated.

Coordinate conventions and output types affect scoring; a click point cannot satisfy a required box selection.

Product perspective

It helps developers diagnose targeting, without measuring end-to-end application success; code and data use MIT and CC BY licenses.
