Remembering the subject is enough to start

A person searching old files often remembers an event rather than a filename: an early-exit clause in a lease, or a birthday present mentioned in a note. Instant’s public example places that recollection in a search box, lists candidate files and shows the matching source passage. The person can inspect the original rather than first receiving a newly composed answer. That matters for retrieval tasks where surrounding conditions are part of the result. A related sentence is useful only if the reader can see whether the adjacent text changes its meaning. The visible source preview makes that judgment part of the same interaction.

Index first, then search in your own words

After downloading the app, the user chooses folders and invokes search with Option-Space or another shortcut. The site lists PDFs, scans, Word documents, Markdown and several image formats. In the Product Hunt explanation, the maker attributes retrieval to Perplexity embedding models and a late-interaction approach intended to retain finer matching detail than one vector for an entire document. A precise model version and reproducible benchmark were not provided. The useful distinction is therefore operational: query wording need not reproduce the document’s wording, while the output still identifies a file and relevant location. The advertised 95 percent hit rate remains a vendor claim with an unspecified evaluation set.

Offline search has an initialization cost

The website says files and queries stay on the Mac, without an account, after a one-time download of an approximately 1 GB model. Update checks and optional anonymous usage counts are separate network activities. The maker also answered public questions about offline operation and telemetry, but no independent traffic audit was available. Initial indexing is another cost: the vendor estimates minutes for an ordinary document collection and potentially hours for a large photo library, followed by incremental indexing of changed files. A regularly used personal archive is consequently a more plausible fit than a large temporary folder searched only once. Those timing estimates are not measurements from this report.

Keep personal search separate from enterprise integration

The personal Mac app is free, requires macOS 15 or later and is optimized for Apple Silicon. It does not require moving scattered files into a new knowledge application, but it does require access to chosen folders and a maintained local index. The separate enterprise offering describes evaluation on customer questions and deployment within customer infrastructure; it is not the same turnkey free download, and no enterprise price is listed. The October 23 Product Hunt board establishes a dated public discovery without a precise original launch time. Ordinary file search remains direct when names and locations are known. Instant addresses the less tidy situation in which remembered meaning is the strongest clue available.
